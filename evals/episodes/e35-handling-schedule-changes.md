# e35 学級閉鎖の朝に、連絡してその日の予定を組み直す

すべて架空の話。このハッカソンの期間中に新しく書いた。

## どんな例か

予定変更への対応力の 3 つの行動が、一つの出来事の中でそろう。朝に急に学校が休みになった答え（1 つ目）に「急に予定が変わる」、パート先と母に自分から電話した答え（2 つ目、3 つ目）に「関わる人に連絡する」、午前と夕方の過ごし方を決め直した答え（4 つ目）に「変更に合わせて、あとの予定を組み直す」が出る。根拠ありにし、本人の言葉を引けるかを見る。いつもの様子と比べてはいないので変化への気づきは、相手に合わせて説明を変えてはいないので相手に応じた説明力は、根拠ありにしない。

## 利用者の答え

- 先週の木曜の朝 7 時ごろ、学校から、学級閉鎖で今日から 3 日間お休みになるとメールが来て、急に上の子が家にいることになりました。
- その日は午前中にパートが入っていたので、私がすぐにパート先に電話をして、今日は休ませてほしいと伝えました。
- 午後に近くに住む私の母が来る約束もしていたので、母にも電話をして、来週に延ばしてほしいと私から頼みました。
- そのうえで、午前は上の子の課題を一緒に見て、買い物は夕方に上の子を連れて行くことにして、その日の予定を組み直しました。
- 3 日間、なんとか家の中で過ごせました。
