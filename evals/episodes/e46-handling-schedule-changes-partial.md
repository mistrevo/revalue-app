# e46 急な休みの連絡をしたところまで

すべて架空の話。このハッカソンの期間中に新しく書いた。

## どんな例か

予定変更への対応力の行動のうち、急な予定の変更と、関わる人への連絡までは話すが、あとの予定の組み直しは話さない。聞かれても「そのあとはその場で考えました」と答える。要確認にし、足りない行動（変更に合わせて、あとの予定を組み直す）だけを聞き返せるかを見る。

## 利用者の答え

- 先週の月曜の朝、子どもが熱を出して、急に保育園を休むことになった日のことです。
- その日はパートに出る予定だったので、私から職場の責任者に電話をして、お休みをもらう連絡をしました。
- 夫にも、お迎えの当番を代わってもらえないかとメッセージを送りました。
- そのあとのことは、その場その場で考えただけで、特に組み直したりはしていません。
- 夕方には熱が下がって、子どもはよく眠っていました。
