# スタイル: revalue-motion

製品の画面と地続きに見せる。落ち着いて、誠実で、派手でない。数字と本人の言葉を見せる場面で、動きが前に出ないようにする。

## パレット（製品の `src/web/src/index.css` から）

| 役割 | 色 |
|---|---|
| 地 | `#F2F4F1` |
| 面（カード） | `#FFFFFF` |
| 文字 | `#262A2B` |
| 控えめな文字 | `#5B6265` |
| 枠線 | `#E1E5E2` |
| 強調（製品の緑） | `#1F7A6E` |
| 強調の上の文字 | `#FFFFFF` |
| 薄い強調 | `#DCEFEA`（文字は `#1B3B36`） |

## 書体

BIZ UDP ゴシック（`BIZ UDPGothic`、400 と 700。OFL）。製品の画面と同じ。

## 動きの性格

- 入場は `outExpo`、大きな面は `outQuint`、中の移動は `inOutCubic`、退場は `inQuart`
- 文字は短いフェードで出す。見出しだけ少し動かす（14〜18px）
- 跳ねは s05 のチェックの印 1 回だけ（`outBack`）
- 点滅なし。常時の寄りなし

## 構図

左揃えの格子を基本にする。中央揃えは s01 の「空白」と s07 の締めだけ。角丸のカードは製品の画面と同じ大きさ（24px）。

## モチーフ

途切れた 1 本の線。s01 では点線の「空白」で、s07 で本人の言葉のあとにつながる。

## 既定から外すこと

- なし

## 禁止

- 「診断」「判定」「スコア」「適職」「不得意」「根拠なし」
- 汎用アイコン、絵文字、外から持ってきた絵
- 紫のグラデーション、グロー、粒子
