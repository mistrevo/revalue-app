# 業務マスターの値と範囲

2026-11-05。仕事の選択肢のもとにする職種と業務を、3 職種 12 業務から業務マスター（10 の領域、30 の職種、125 の業務。カードに使うのは 115）に置き換えるときに決めたことを残す。進め方は [設計](../superpowers/specs/2026-11-05-ability-dictionary-design.md) の「3. 業務マスター」。正しい姿は [05-options.md](../specs/05-options.md) の「登録した職種と業務」。

業務マスターは、当事者の協力者へのインタビューで得た業務の一覧をもとに、Claude が書き起こした。協力者の資料はリポジトリに入れていない。

## 決めたこと

| 決めたこと | 決めた人 | 外した案 | 理由 |
|---|---|---|---|
| カードに使う（`active`）のは、10 の領域のうち、job tag の職業とタスクが見つかった業務 | Claude | 家でできる短い時間の業務が多い 5 領域だけを `active` にする | 5 領域だけでは、走破力と粘り強さにつながる業務が 0 になり、回復力が 1 つで、どの力にも 2 つ以上の業務をつなぐことができない。補助の力に無理に足すより、中身の合う業務を使うほうが、カードの理由が業務から離れない。外に出る業務は、本人が「家でできることだけ」を選べばカードから外れる |
| 前からある 12 業務のうち、協力者の業務と重なる 7 つは 1 つにまとめ、id を残す | Claude | 協力者の業務を新しい id で足し、前の業務を消す | 公開中のアプリに、前の業務の id を持つカード、選んだ案、深めた中身、レポートの版が保存されている。id で業務マスターを引くので、id を残せば読める |
| 時給の目安の下限を 1,300 円以上にそろえる | Claude | 下書きの 1,200 円のまま。地域で変わると添える | 2026 年度の地域別最低賃金は東京都 1,280 円で、1,200 円は東京都などで下回る。下限が 1,300 円未満の業務は下限を 1,300 円に、上限も 1,300 円未満なら 1,300 円にした（カードに使う業務では 51） |
| 保険の営業（6 業務）とキャリアコンサルタント（1 業務）を準備中にする | Claude | カードに使う | 保険を扱うには登録が要り、給与は歩合で決まることが多く、時給の目安と合わない。キャリアコンサルタントは名乗るのに国家資格が要る。どちらも、短い時間から小さく始める選択肢として出せない |
| 業務のデジタル化の支援は、カードに使うままにする | Claude（開発者に確かめる） | 準備中にする | job tag では経験を積んだ人の職業だが、業務の中身は短い時間から手伝える形に書いている。短い時間から始められるかは開発者に確かめる |
| 業務の主な力と補助の力は、どちらも業務がその力に「つながる」と数える | Claude | 主な力だけを数える | 設計の点検で決めた。主な力だけでは、話から確かめる 22 の力のうち 8 つで、つながる業務が 2 つに届かない |
| 業務の力に準備中の力が入っていてもよい。つながるに数えるのは、話から確かめる力だけ | Claude | 準備中の力を業務の力から外す | 準備中の力を戻したときに、業務マスターを書き直さずに使える。カードの力にはならない |
| 仕事の選択肢の AI に渡す候補は、条件に合い、本人の使える力のどれかにつながる業務だけにする。「組み合わせる」は、どの業務も使える力のどれかにつながる組み合わせになる | Claude | 条件に合う業務をすべて渡す | 115 業務がすべて条件に合うと、1 回に渡す文が数万字になる。理由が業務から離れないため |
| 力が生きる場面は、カード、深める、レポートの選んだ案で、使った力を主な力に持つ業務に添える。理由と力を出さないときと、レポートの前の版には出さない | Claude | 補助の力のカードにも添える | 場面の文は主な力を中心に書いてある |
| 小さな試し方は、深める AI に一歩の手がかりとして渡すだけにする。画面にはそのまま出さない | Claude | 一歩の候補として画面に並べる | 一歩は本人の条件で決めるので、AI が条件と照らして書く |
| 本人に確かめる条件は、深めるとレポートの「まだ確かめていないこと」に一行で出し、レポートの前の版にも残す。カードの絞り込みと力の確かめには使わない | Claude | カードの絞り込みに使う | 本人の状態ではなく業務の値で、知識や道具と同じ扱いにする |
| 広告の効果の比較（力がどちらも準備中）は、カードに使う業務のまま置く | Claude | 準備中にする | いまはどの使える力にもつながらないのでカードに出ない。準備中の力を戻したときに使える |

## まだ分かっていないこと

- needsReview の 87 業務の使う力。Claude が付け替えたか足したもので、協力者に確かめる
- 時給の目安の出典。どの業務も Claude の下書きで、求人の相場で確かめていない
- 業務のデジタル化の支援を、短い時間から始められるか
