# 最初の問いを、気持ちが動いた日を聞く形にする

2026-11-05。PRD の [3-features.md](../prd/3-features.md) の discover-1（具体的な一日を一つ聞く）と、[4-rules.md](../prd/4-rules.md) の「最初の問い」の理由を残す。

## なぜ変えるか

- 当事者の協力者から、最初に聞く問いについて、次の一言をもらった。「最近の一日」ではなく「〜と感じた日のことを教えてください」と聞く。成功体験や達成感、失敗、立ち直りを引き出す方向にする
- 架空の 6 人を AI が演じた評価（2026-11-04）でも、「たとえば昨日」の問いでは話したい日を出しにくかった。4 人が自分で別の日に切り替え、1 人は 5 往復のあとに「去年の話でもいいか」と聞いた
- 変えると決めたのは開発者。言葉と選択肢は Claude の判断で、当事者の協力者のレポートを見て変える

## 決めたこと（Claude の判断）

| 決めたこと | 外した案 | 理由 |
|---|---|---|
| 選択肢を「うまくいったと感じた日」「大変だったけど、乗り切った日」「思うようにいかなかった日」の 3 つにする | 成功体験だけを聞く（「うまくいった日」「達成感があった日」） | 「私には何もない」と思っている人が答えにくい。結果の良し悪しで見立てを変えない決まりとも食い違う |
| 選択肢を気持ちの向きで分ける | 出来事の種類で分ける（いまの「家族と出かけた」など） | 協力者の一言に沿う。気持ちの向きなら、特定の力の核となる行動に寄らない |
| 別の日の入口のきっかけも、同じ 3 つにする | 08 revisit（別の日に話す）で決めた「予定がずれた日」など、別の 3 つ | 入口が 2 種類あると、どちらを直すかが分かれる。協力者のレポートで変えるときに 1 か所で済む |
| 話を飛ばしたあとと、つらい状態のサインで終わった人の入口では、「思うようにいかなかった日」を出さない | どこでも同じ 3 つを出す | 重い日に話を戻さない決まりがある |

## まだ分かっていないこと

- 「気持ちが動いた日」を、重く感じる人がいないか。試用と協力者のレポートで見る
- 最初に選んだ気持ちの向きが、そのあとの聞き方に影響するか。いまは選んだ日のことを具体的に聞くだけにする
