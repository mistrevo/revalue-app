# 画面の文字を BIZ UDP ゴシックにする

2026-11-06。[00-common.md](../specs/00-common.md) の「見た目」にある文字の決まりの理由を残す。

## なぜ変えるか

- 画面を作り直したとき、やわらかく見えるよう、丸ゴシックの M PLUS Rounded 1c にした
- 開発者が PC（Windows）で見ると、文字ががたがたして読みにくかった
- 拡大すると、字ごとに線の太さがばらつき、行の中で字の高さもそろっていなかった。このフォントには、Windows で小さな字をきれいに描くための調整（ヒンティング）が入っていない。また、ひらがなが漢字より小さめに作られている

## 比べたもの

同じ文（案内の約束と、聞き手の問い）を、開発者のふだんのブラウザで並べて比べた。

| フォント | 見え方 |
|---|---|
| M PLUS Rounded 1c（いま） | 丸ゴシック。PC の小さな字で線がばらつく |
| Zen Maru Gothic | 丸ゴシック。線が細めで、字の大きさはそろう |
| Kosugi Maru | 丸ゴシック。太字を持たないので、見出しの太字はブラウザが太らせたものになる |
| BIZ UDP ゴシック | 読みやすさを優先して作られたフォント（UD はユニバーサルデザイン。年齢や見え方にかかわらず読みやすく作る考え方）。Windows にも入っている |
| 游ゴシック UI、メイリオ | Windows の標準。ほかの端末では別のフォントになる |

## 決めたこと

- BIZ UDP ゴシックにする（開発者の決定）。丸ゴシックのやわらかさより、読みやすさを先にした
- 太さは、本文の 400 と、見出しとボタンの 700 の 2 つ。このフォントにはこの 2 つしかない
- いままでどおり、アプリの中から配る（fontsource の `@fontsource/biz-udpgothic`）。スマホでも同じ字になる。アプリに入れた版と、比べたときに読み込んだ版（Google Fonts）を同じ文で描くと、字の形は同じで、違いは字の縁の数ピクセルの濃さだけだった
