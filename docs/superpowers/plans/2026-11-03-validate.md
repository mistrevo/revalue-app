# 03 validate（確かめる） Implementation Plan

> **For agentic workers:** このリポジトリでは run-plan スキル（Workflow）で回す。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 話した場面の本人の言葉を根拠に 3 つの力を確かめ、足りない行動を会話の中で聞き返し、話し終えた場面に「見えたこと」を出し、訂正・続き・外す・履歴をそろえる。

**Architecture:** 02 discover（話す）の 1 往復（読み取り → 次の一手 → 返事）の「読み取り」の構造化出力に、核となる行動の根拠の候補を足す。候補はコード（`EvidenceChecker`）が本人の答えと一字一句照らし合わせ、状態はコード（`AbilityStates`）が決め、次の一手もコード（`NextMovePolicy`）が「足りない行動を一つ聞く」を選ぶ。利用者ごとの力の状態と履歴は `AbilityBookItem` 1 件に持ち、保存のたびに場面から計算し直す。

**Tech Stack:** .NET 10 Minimal API、Anthropic C# SDK 13.x（`claude-opus-5-5`）、xUnit、React 19 + TypeScript + Vite + Tailwind 4 + shadcn/ui、Vitest + Testing Library、Playwright MCP。

**Spec:** `docs/specs/03-validate.md`。あわせて `docs/specs/00-common.md`、`docs/specs/00-tech-stack.md`、`docs/specs/02-discover.md`、PRD の `docs/prd/4-rules.md` と `docs/prd/6-quality.md` を読む。

## Global Constraints

- 回答・文書・コミットメッセージは日本語。呼び名はタイトルとセットで書く（例: validate-1（3 つともそろったときだけ根拠あり））
- テスト名（xUnit の DisplayName、Vitest の it の名前）は `validate-N（タイトル）: …` で始める
- テストでは Claude を呼ばない。本物を呼ぶのは評価だけ
- 画面と AI の言葉に使わない言葉: `src/shared/forbidden-words.json`（診断、判定、スコア、根拠なし、不得意、不十分、まだ強みとは言えません、あなたに向いている仕事は、適職、合否）。状態の呼び名（根拠あり、要確認、未確認）とチェック表、点数、順位を画面に出さない
- 画面の文言は `src/web/src/copy.ts`。力の名前と行動の手がかりは裏側の `AbilityText` の 1 か所に置き、API で渡す（画面に写さない）
- ログに話した内容、引用、AI の返答を書かない（common-2（ログに中身を書かない））
- 保存は「読んだときから変わっていないときだけ書く」（`TryUpdateAsync`、`TryReplaceAsync`、`TryDeleteAsync`）。消えたアイテムを作り直さない
- 送ると 400 になるもの（Opus 5.5）: thinking の無効化、`budget_tokens`、`temperature`・`top_p`・`top_k`、prefill、`tool_choice` の `any`・`tool`
- 1 往復で AI を呼ぶのは 2 回（読み取りと返事）のまま
- 架空エピソードはすべて架空。このハッカソンの期間中に新しく書いたと各ファイルに書く
- 鍵、実在の人の情報、開発者の名前を入れない（`.claude/hooks/guard.mjs` が止める。止められたら中身を直す）

## Review Focus

1. AI が、聞き手の問いや選択肢の中の言葉（本人の答えにない言葉）を根拠として返す → 捨てる。Task 1 のテスト `QuoteOnlyInAssistantTurnIsDropped`
2. AI が本人の言葉を少し整えて返す（「8 時」→「8時」、句点を足す）→ 一字一句でないので捨て、例外にしない。Task 1 のテスト `NormalizedQuoteIsDropped`
3. AI が範囲外の番号（答えの番号 0 や答えの数より大きい、行動 4、出来事 0）を返す → 捨て、例外にしない。Task 1 のテスト `OutOfRangeCandidatesAreDropped`
4. 続きを話すのと同時に、ほかの画面で新しい場面を始める → 途中の場面は 1 つ。続けた場面は話し終えた状態に戻す。Task 5 のテスト `ResumeRaceKeepsOneTalkingEpisode`
5. 訂正を、話している途中の場面や力の確かめに使わない場面に送る、空や長すぎる訂正を送る → 409 / 400 で、何も保存しない。Task 5 のテスト `CorrectionRejectsWrongStateAndInvalidText`

### Task 1: 力と根拠の照らし合わせ、場面ごとの状態（コードだけ）

**Files:**
- Create: `src/Revalue.Server/Features/Validate/Ability.cs`、`AbilityText.cs`、`Evidence.cs`、`AbilityStates.cs`
- Modify: `src/Revalue.Server/Features/Discover/EpisodeItem.cs`（`AnswerKind.Correction` を足す）
- Test: `tests/Revalue.Server.Tests/EvidenceTests.cs`、`tests/Revalue.Server.Tests/AbilityStatesTests.cs`、`tests/Revalue.Server.Tests/AbilityTextTests.cs`

**Interfaces:**
- Produces:
  - `enum Ability { Noticing, Coordinating, Prioritizing }`。JSON は `noticing`、`coordinating`、`prioritizing`（`JsonStringEnumMemberName`）。並びはこの順（表示と同点の選び方に使う）
  - `enum AbilityState { NotYet, NeedsCheck, Confirmed }`。JSON は `notYet`、`needsCheck`、`confirmed`
  - `sealed record ActionRef(Ability Ability, int Number)`。`ToString()` は `"coordinating.3"` の形。`static ActionRef? Parse(string)`
  - `AnswerKind.Correction`（JSON `correction`）
  - `static class AbilityText`: `string Name(Ability)`（見立てる力、調整する力、優先順位をつける力）、`string Hint(ActionRef)`（Spec の手がかりの表の言葉そのまま）、`string ResumeQuestion(ActionRef)` = `"この場面の続きを聞かせてください。" + Hint + "について、覚えていることはありますか？"`（Claude の判断）、`IReadOnlyList<string> ResumeChoices` = 「少し覚えています」「よく覚えていません」「その日のほかのことを話したい」
  - `sealed record EvidenceCandidate(Ability Ability, int Action, string Quote, int Answer, int Event, bool General, string LinkedQuote, int LinkedAnswer)`。`Answer` と `LinkedAnswer` は本人の答えの番号（1 から。user のターンだけを数える）。結びつきがないときは `LinkedQuote = ""`、`LinkedAnswer = 0`
  - `sealed record Evidence(Ability Ability, int Action, string Quote, int Answer, int Event, bool General, bool FromChoice, string? LinkedQuote)`（保存する形）
  - `static class EvidenceChecker { IReadOnlyList<Evidence> Check(IReadOnlyList<Turn> turns, IEnumerable<EvidenceCandidate> candidates) }`
  - `static class EvidenceSet { IReadOnlyList<Evidence> Merge(IReadOnlyList<Evidence> known, IReadOnlyList<Evidence> found) }`: known に found を足す。同じ（力、行動、引用、答えの番号）は 1 つにする。known から消さない
  - `sealed record AbilityResult(Ability Ability, AbilityState State, IReadOnlyList<Evidence> Shown, IReadOnlyList<int> Missing)`
  - `static class AbilityStates { IReadOnlyList<AbilityResult> Evaluate(IReadOnlyList<Evidence> evidence) }`: 3 つの力を `Ability` の順で返す

照らし合わせの決まり（`EvidenceChecker.Check`）:
- `Action` が 1〜3、`Event` が 1 以上、`Answer` が 1〜本人の答えの数でなければ捨てる
- `Quote` が空白だけ、または `Answer` 番目の本人の答えの文に `string.Contains(quote, StringComparison.Ordinal)` で含まれなければ捨てる
- その答えが `AnswerKind.Choice` なら、`LinkedAnswer` が別の本人の答え（`Free` か `Correction`）を指し、その文に `LinkedQuote` が一字一句含まれるときだけ残す（`FromChoice = true`、`LinkedQuote` を持つ）。そうでなければ捨てる（validate-5（選んだだけでは根拠にしない））
- 自由な答えと訂正の根拠は `FromChoice = false`、`LinkedQuote = null`

状態の決まり（`AbilityStates.Evaluate`）:
- Confirmed: `General == false` の根拠で、同じ `Event` に行動 1・2・3 がそろう出来事がある。`Shown` はその出来事の行動 1〜3 の根拠を 1 つずつ（同じ行動が複数あれば答えの番号が小さいもの）。そろう出来事が複数あれば、番号の大きい出来事。`Missing` は空
- NeedsCheck: Confirmed でなく、根拠が 1 つ以上ある。いちばん多くの行動がある出来事（`General == false`。同数なら番号の大きい出来事）の根拠を `Shown` に、その出来事で足りない行動を `Missing` に入れる。一般論の根拠しかなければ、一般論の根拠を `Shown` に、`Missing` は 1〜3 のうち一般論でも見つかっていないもの
- NotYet: 根拠がない。`Shown` も `Missing` も空

### Task 3: 読み取りに根拠の候補を足し、1 往復で保存する

**Files:**
- Modify: `src/Revalue.Server/Ai/IConversationAi.cs`、`ClaudeConversationAi.cs`、`ScriptedConversationAi.cs`、`Ai/Prompts/reader.md`、`Ai/Prompts/listener.md`
- Modify: `src/Revalue.Server/Features/Discover/TalkRound.cs`、`TalkStream.cs`、`EpisodeItem.cs`（`EpisodeItem.Evidence`）
- Modify: `tests/Revalue.Server.Tests/FakeConversationAi.cs`、既存のテストの呼び出し
- Test: `tests/Revalue.Server.Tests/ClaudeConversationAiTests.cs`、`TalkStreamTests.cs`

**Interfaces:**
- Consumes: Task 1、Task 2
- Produces:
  - `TurnReading(IReadOnlySet<AnswerSignal> Signals, IReadOnlyList<EvidenceCandidate>? Candidates = null)`。`Candidates` が null なら空として扱う（既存の呼び出しを壊さない）
  - `IConversationAi.StreamReplyAsync(IReadOnlyList<Turn> turns, NextMove move, CancellationToken ct)`（`MoveKind` から変える）
  - `EpisodeItem.Evidence`（`IReadOnlyList<Evidence>`、既定は空）
  - `sealed record RoundContext(IReadOnlyList<Turn> Turns, IReadOnlyList<Evidence> Known, int UserTurnNumber, int TurnLimit)`
  - `TalkRound.RunAsync(IConversationAi ai, RoundContext context, TimeProvider time, CancellationToken ct)`
  - `RoundStep.Decided(TurnReading Reading, NextMove Move, IReadOnlyList<Evidence> Evidence)`。`Evidence` は `EvidenceSet.Merge(Known, EvidenceChecker.Check(Turns, Reading.Candidates))`
  - 返事のターンに `Target`（AskMissingAction のとき）を入れる
  - `TalkStream` は保存のとき、`Evidence` を場面に書く（つらい状態のサインのときは書かない）。往復の上限は `episode.TurnLimit`

読み取りの渡し方（`ClaudeConversationAi.BuildReadParams`）:
- 会話を 1 つの user メッセージの文にする（Claude の判断）。聞き手の言葉は `聞き手: …`（選択肢があれば `（答えの例: a / b / c）` を続ける）、本人の答えは `[答え N]（自由に書いた）…`、`[答え N]（選択肢から選んだ）…`、`[答え N]（訂正）…`。全体を `<conversation>…</conversation>` で囲み、最後に「いちばん最後の答えが、いまの答えです。」と添える
- スキーマ: これまでの 5 つの真偽に、`evidence`（配列。要素は `ability`（`noticing` / `coordinating` / `prioritizing` の enum）、`action`（integer）、`quote`、`answer`（integer）、`event`（integer）、`general`（boolean）、`linkedQuote`（string）、`linkedAnswer`（integer）。すべて required、`additionalProperties: false`）を足す
- `ParseReading` は、形の合わない要素を捨てる（例外にしない）

返事の渡し方（`BuildReplyParams`）: `AskMissingAction` のときだけ、system メッセージを `<next_move>AskMissingAction</next_move>\n<hint>{AbilityText.Hint(target)}</hint>` にする。ほかの一手は今のまま。

`reader.md` に足すこと（文は Claude が書く。voice-reviewer と開発者の確認の対象）:
- 力と核となる行動の表（Spec の表と同じ中身）
- 場面のやりとり全体を読み、行動ごとに根拠の候補を返す。`quote` は本人の答えから一字一句そのまま抜き出す（言い換え、句読点の足し引き、数字や空白の書き換えをしない）。聞き手の言葉や答えの例からは取らない
- `event` は、この場面の中の具体的な出来事に、出てきた順に 1、2、… と振った番号
- 「いつも〜している」のような一般論として話された行動は `general: true`
- 選択肢から選んだ答えを根拠にするときは、結びつく、自由に書いた答えか訂正の言葉を `linkedQuote` と `linkedAnswer` に入れる。なければ候補にしない
- 結果の良し悪しや、結果を話したかどうかで判断を変えない（validate-3（結果で見立てを変えない））
- 訂正は、前の答えより優先する。訂正で打ち消された行動は候補にしない
- 本人以外（家族など）がした行動は、本人の行動として候補にしない
- 見つからなければ `evidence` は空

`listener.md` に足すこと:
- `AskMissingAction`: 話してくれた出来事の中で、`<hint>` の手がかりについてだけ、一つ聞く。手がかりの言葉をそのまま読み上げず、その場面に合わせた具体的な問いにする。答えの例に、手がかりの行動を正解のように並べない。「その場面で、ほかに〜しましたか？」のように、したことを前提にした聞き方をしない
