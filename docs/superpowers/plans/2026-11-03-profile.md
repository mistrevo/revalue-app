# 04 profile（5 つの記録） 実装計画

> **For agentic workers:** この計画は run-plan スキル（Workflow）で回す。手順はチェックボックス（`- [ ]`）で進み具合を記録する。

**Goal:** できること、好み、やりたいこと、条件、主体性を別々に残し、本人が答えて直せる「5 つの記録」の API と画面を作る。

**Architecture:** 利用者ごとに 1 件の `ProfileItem`（id `profile`）に、好み・やりたいこと・条件・主体性と「どの問いに答えたか」を持つ。できることは保存せず、`GET /api/profile` のたびに 03 validate（確かめる）の `AbilityBook.View` から作る。AI は呼ばない。画面 `/profile` は、まだ答えていない問いを一つだけ上に出し、その下に 5 つの記録を並べる。

**Tech Stack:** ASP.NET Core（.NET 10）Minimal API、System.Text.Json、xUnit。React 19 + TypeScript + Vite + Tailwind 4 + shadcn/ui、Vitest + Testing Library。Playwright MCP。

**Spec:** `docs/specs/04-profile.md`（あわせて `docs/specs/00-common.md`、`docs/specs/00-tech-stack.md`、`docs/specs/03-validate.md`）

## Global Constraints

- 回答・文書・コミットメッセージは日本語。呼び名はタイトルとセット（例: profile-5（好みとやりたいことを一つずつ聞く））
- テストの名前（DisplayName / `it` の文）は `profile-N（タイトル）: …` の形にする
- 使わない言葉（`src/shared/forbidden-words.json`）を、画面の文言と裏側の問い・選択肢に入れない。状態の呼び名（根拠あり、要確認、未確認）、点数、順位を画面に出さない
- 画面の文言は `src/web/src/copy.ts`、問いと選択肢（裏側で照らし合わせる言葉）は `src/Revalue.Server/Features/Profile/ProfileText.cs` の 1 か所に置く
- このまとまりでは AI を呼ばない。送信回数の上限も数えない
- 保存は利用者キーごと。了解（`RequireConsent()`）が要る。ログに書いた内容を出さない
- 文字数は `StringInfo.LengthInTextElements` で数える（02 discover（話す）と同じ）。前後の空白は落としてから数える
- 好みの問い「どんな進め方や環境が、自分に合っていると思いますか？」、選択肢「自分のペースで進められる」「人とやりとりしながら進められる」「決まった手順がある」
- やりたいことの問い「これからやってみたいことや、目指したいことに近いものはありますか？」、選択肢「家にいながらできることを始めたい」「人の役に立つことをしたい」「新しいことを覚えたい」
- 好みとやりたいことの問いには「いまは決めない」、主体性には「いまは書かない」を置く。済んだあとの記録の欄は、好みとやりたいことが空なら「まだ決めていません」、主体性が空なら「まだ書いていません」
- 条件の値: 時間帯 `morning`（朝（9 時まで））/ `daytime`（日中（9〜15 時））/ `evening`（夕方（15〜18 時））/ `night`（夜（18 時から））。週あたりの時間 3, 5, 10, 15, 20, 30, 40。場所 `homeOnly`（家でできることだけ）/ `canGoOut`（外に出ることもできる）。月の収入の目安 1, 3, 5, 8, 10, 15, 20（万円）か null（まだ決めていない）
- 主体性の欄の見出しは「自分で選び、動き出すときに大事にしたいこと」
- progress.md は書き換えない

## Review Focus

1. 2 つの画面で好みとやりたいことを同時に保存する → どちらも残る（片方がもう片方を上書きしない）。Task 1 の `ConcurrentUpdatesKeepBoth`
2. まだ何も答えていない人が開く → 404 ではなく、空の記録と「どれも答えていない」が返る。Task 1 の `FirstVisitReturnsEmptyProfile`
3. 空白だけの言葉や、同じ言葉を 2 回足す → 空白だけは 400、同じ言葉は 1 つにまとめる。Task 1 の `EntriesAreTrimmedAndDeduplicated`
4. 「全部消す」のあと → 5 つの記録も消え、了解し直すと空から始まる。Task 1 の `DeleteAllRemovesProfile`
5. 知らない値（`"timeSlots": ["midnight"]`、`"place": "space"`）→ 500 ではなく 400 で、何も保存しない。Task 1 の `UnknownEnumValuesAre400`
