# 07 report（可能性レポート）

## 目的

確かめた力と根拠の本人の言葉、まだ確かめていないこと、5 つの記録、選んだ案、仕事の場面での考え方、最初の一歩を、一つの画面にまとめて示す。本人はレポートから、直す、保留する、次の一歩を選ぶか書く、のどれでもできる。内容が変わったら版を増やし、前の版と、何が変わったかを残す。

達成するユースケースは「次の一歩を決める」（[2-usecases.md](../prd/2-usecases.md)）。言葉とデータの決まりは [00-common.md](00-common.md) にある。まとめる記録を作るのは、[03-validate.md](03-validate.md)（確かめる）、[04-profile.md](04-profile.md)（5 つの記録）、[05-options.md](05-options.md)（仕事の選択肢）、[06-deepen.md](06-deepen.md)（選んだ案を深める）。

## 振る舞い

### 進める条件

話し終えた場面が一つ以上あれば、レポートを開ける。案を選んでいなくても、保留していても開ける（report-5（保留しても開ける））。保留中とまだ選んでいないときは、前に選んでいた案の考え方と一歩は出さない（Claude の判断）。話し終えた場面がなければ、ホームから話せることを伝え、そこへの道を出す。

続きを話している場面は、話し終えるまで、話し終えた場面に数えない（05 options（仕事の選択肢）と同じ）。そのため、話し終えた場面が一つだけで、その続きを話しているあいだは、レポートを開けない（Claude の判断）。

### まとめる中身

レポートは、開いたときの記録から、コードが組み立てる。AI は呼ばない。まとめるだけで、新しい見立てや言い切りを作らないため（report-1（一つにまとめて示す）、report-4（決めつけない）。Claude の判断）。

並べる順と中身は次のとおり（Claude の判断）。

| 欄 | 中身 | 元の記録 |
|---|---|---|
| できること | 確かめた力を、根拠ありの力（「あなたの話から見えた力」）と要確認の力（「確かめ中（もう少し聞かせてほしいことがあります）」）に分けて並べる。力ごとに根拠の本人の言葉を「」で添える | 03 validate（確かめる）の力の状態 |
| まだ確かめていないこと | まだ聞けていない力、確かめ中の力（もう少し聞かせてほしいことがある）、選んだ案の業務で使う力のうちまだ確かめていない力、業務に要る知識や道具。まだ聞けていない力か確かめ中の力があれば、まだ話に出てきていないだけで、力がないわけではないと添える。仕事の場面で発揮できるかはまだ確かめていないことも添える（[03-validate.md](03-validate.md) と同じ） | 03 validate（確かめる）の力の状態、06 deepen（選んだ案を深める）の業務ごとの照らし合わせ |
| 5 つの記録 | できること（上の「できること」の欄と同じ中身なので、その欄を指す）、好み、やりたいこと、条件、主体性（動き出すときに大事にしたいこと） | 04 profile（5 つの記録） |
| 選んだ案 | 選んだカードか、本人が書いた仕事の名前と中身。カードなら、理由と、もとにした力と根拠の言葉も出す。もとにした力を本人が外したときや、カードの力の状態がいまの記録と合わないときは、理由と力を出さず、05 options（仕事の選択肢）と同じ一言を添える。いまの条件に収まっていなければ、05 options（仕事の選択肢）と同じ一言を添える。「創る」なら、需要はまだ確かめていないと添える。保留なら保留していることを書く。まだ選んでいなければそのことと、選ばずにおいても保留にしてもかまわないことを書く（Claude の判断） | 05 options（仕事の選択肢）の選んだ案 |
| 仕事の場面での考え方 | 仮の場面の問いと、本人の答え（答えた問いだけ）。答えは考え方として残したもので、力の見立てには使っていないと添える | 06 deepen（選んだ案を深める）の問いと答え |
| 最初の一歩 | 本人が選んだ一歩の候補と、書いた一歩。選んだ候補がいまの条件の外なら、06 deepen（選んだ案を深める）と同じ一言を添える | 06 deepen（選んだ案を深める）の一歩 |

- 本人が外した力は使わない（[5-information.md](../prd/5-information.md)）。選んだ案の業務の「使う力」を外していれば、その力の名前は出さずに、外した見立てはここには出していないと添える（[04-profile.md](04-profile.md) と同じ言い方。Claude の判断）。前の版を見るときも、いま外している力は出さない
- 選んだ案は「あなたが選んだ案」として書く。「あなたに向いている仕事は」のような言い方をしない（report-4（決めつけない））
- 選んだ案をまだ深めていないときは、考え方と一歩の欄に、案を深めると出せることを書く。深める画面への道も出す。選んだ案が変わって、深めた中身が古いときも同じにする。保留中とまだ選んでいないときは、案を選んで深めると出せることを書き、仕事の選択肢への道を出す（深める画面は、案を選んでいないと開けないため）（Claude の判断）
- 答えた問いがない、一歩を決めていない、案を選んでいないときは、そのままにしておいてもかまわないと添える（Claude の判断）
- まだ確かめていないことの欄の業務は、選ぶ・組み合わせるなら登録の業務から出す。「創る」と本人が書いた仕事は、いまの案で深めた中身があるときだけ、その見立ての業務を出す（Claude の判断）
- 根拠の本人の言葉と「（選んだ答え）」の見せ方は [00-common.md](00-common.md) の「言葉」に従う。考え方の答えは「あなたの答え」として出す

### 直す、保留する、次の一歩を選ぶ

レポートから、次のどれでもできる（report-2（直す、保留する、次の一歩を選ぶ））。どれも AI を呼ばない。

- 直す: 欄ごとに、その記録を直せる画面への道を出す。できることとまだ確かめていないことは見えた力の画面、5 つの記録は 5 つの記録の画面、選んだ案は仕事の選択肢の画面、考え方は深める画面。最初の一歩は、レポートの中で選び直して書ける（下の行）。深めた中身を読めないときは、一歩の欄に深める画面への道を出す（Claude の判断）。まだ確かめていないことは、本人の誤りや欠けではない。そのため、その道は「見えた力の画面で見る」とし、「直す」とは書かない（Claude の判断）
- 保留する: 選んだ案があれば「保留する」を出す。押すと、05 options（仕事の選択肢）の選んだ案を保留にする（`PUT /api/options/choice`）
- 次の一歩を選ぶか書く: いまの案で深めた中身があれば、最初の一歩の欄の「一歩を選び直す・書く」で、06 deepen（選んだ案を深める）と同じ一歩の候補 3 つと書く欄を開き、選んでも自分で書いても保存できる（`GET /api/deepen` と `PUT /api/deepen/steps`）。1 つでも複数でもよい

### 版を残す

レポートの中身が変わったら、前の版を残し、いつ何が変わったかを分かるようにする（report-3（版を残す））。

- 開いたときに、いまの中身の指紋（中身から作る短い値。中身が変わると値も変わる）を、いちばん新しい版の指紋と比べる。違えば版を一つ増やして残す。初めて開いたときは第 1 版にする（Claude の判断）
- 版ごとに、作った日時と、欄ごとの指紋と、前の版から変わった欄（上の 6 つの欄の名前）を持つ。欄ごとの指紋には根拠の言葉も入れるので、根拠の言葉だけが変わったときも、変わった欄が分かる。作った日時は、中身が変わったことをレポートを開いて見つけた日時（Claude の判断）
- 版には、その時点の中身を残す。ただし次のものは前の版に出さない（Claude の判断）
  - 根拠の本人の言葉と、選んだ案の理由（根拠の言葉を引いている）は写さない。本人が場面を飛ばしたときに、その言葉を前の版に残さないため。理由と力を出せなかったわけ（外した、記録と合わない）も残さない
  - 力は名前だけを出し、状態は出さない。見えた力と確かめ中の力が分けずに並ぶので、見出しは根拠ありの呼び名にしない。「その時点で並んでいた力（見えた力と、確かめ中の力）」とする
  - まだ確かめていないことの欄は、業務に要る知識や道具だけを出す。まだ聞けていない力、確かめ中の力、業務で使う力のうちまだ確かめていない力は出さない
  - 力の状態と、まだ確かめていない力を出さないのは、前の版と見比べて、見立てが下がったと読ませないため。たとえば、つらい状態のサインで場面を確かめに使わなくなった直後に起こりうる
  - 前の版に出さないものは、保存もしない
- 前の版では、条件に収まらないことと深めていないことを、「この版の時点では」のように、その版の時点のこととして書く。前の版は見るだけなので、いまの操作を勧める文と、直す道は出さない（Claude の判断）
- 本人が場面を飛ばしたら、飛ばしたやりとりが始まった時点（続きを話していた場面なら、続きを始めた時点。続きの問いを足さずに開いたときも同じ）より後に作った版を捨てる。版は力の名前を残すので、飛ばしたやりとりからだけ出た力の名前を、前の版に残さないため。次の版の番号は、残った版の続きになる（Claude の判断）
- 版は新しいものから 10 まで残す（数は Claude の判断）
- また話して記録が変わったら、次に開いたときに版が一つ増える（report-6（話を足したら作り直す））。話しても中身が変わらなければ、版は増やさない（Claude の判断）
- 仕事の選択肢のカードは、05 options（仕事の選択肢）の決まりどおり、仕事の選択肢の画面を開いたときに作り直す。レポートでは、カードが古くなっていれば、仕事の選択肢の画面で作り直せることを伝える（Claude の判断）

### 数える

案を選ぶか保留したうえでレポートを開けたら、人と結びつかない数「可能性レポートまで進んだ人」を 1 人 1 回だけ数える（[01-foundation.md](01-foundation.md) の数える仕組み）。仕事の選択肢を通らずにホームから開いただけでは数えない。[1-value.md](../prd/1-value.md) の「最後まで通る」と「思い立つ」の割合を、流れを通った人で数えるため（Claude の判断）。

### 画面

- `/report` に「可能性レポート」の画面を置く。ホームと、深める画面（[06-deepen.md](06-deepen.md) の「画面」）から入れる
- 画面の先頭で、次の 2 つを伝える。話した言葉と、本人が選んだり書いたりしたことをまとめたものであること。どれもあとから直せること（[00-common.md](00-common.md) の「言葉」）
- 版の番号と作った日時を出す。第 2 版からは、前の版から変わった欄を出す
- 上の 6 つの欄を、表の順に並べる。欄ごとに「直す」の道を出す。道の言葉には行き先の画面の名前を入れる（「5 つの記録の画面で直す」「選んだ案を深める画面で直す」など。Claude の判断）
- できることの欄が空で、本人が見立てを外しているときは、5 つの記録の画面と同じ「外した見立ては、ここには出していません。見えた力の画面で戻せます。」を出す。そのために、いまの中身に、外していなければこの欄に出ていた力を本人が外しているか（`abilitiesExcluded`）を添える。話の中身が足りなくて欄が空のときは添えない。外した力そのものは出さず、前の版には残さない（Claude の判断）
- 読み込めなかったときも、穏やかな言葉とホームへ戻る道を出す
- できることの欄は、中を「あなたの話から見えた力」と「確かめ中（もう少し聞かせてほしいことがあります）」のまとまりに分ける。「あなたの話から見えた力」は根拠ありの力だけを指す言葉なので、確かめ中の力を含む欄の見出しには使わない。分け方は 5 つの記録の画面（[04-profile.md](04-profile.md)）と同じ。5 つの記録の欄のできることは、この見出しを指す（Claude の判断）
- 前の版は「前の版を見る」で開き、版ごとに日時と変わった欄、その時点の中身を出す（上の「版を残す」のとおり、力の状態と根拠の言葉は出さない）
- 状態の呼び名（根拠あり、要確認、未確認）、点数、順位は出さない（[00-common.md](00-common.md) の「言葉」）
- 幅 375px と 1280px で、横にはみ出さない

### API

ログインと了解が要る（[01-foundation.md](01-foundation.md)）。

| API | AI | 振る舞い |
|---|---|---|
| `GET /api/report` | 呼ばない | 次を返す。進めるかどうか。いまの中身（本人が外した力があるかを添える）と、その版の番号、日時、前の版から変わった欄。前の版の一覧（新しいものから。版ごとに番号、日時、変わった欄、その時点の中身。中身からは力の状態を表すものを除く）。あわせて、中身が変わっていれば版を増やして残し、上の「数える」のときは「可能性レポートまで進んだ人」を数える |

- 保留と一歩の書き換えは、05 options（仕事の選択肢）と 06 deepen（選んだ案を深める）の API を使う。一歩を保存するのに要る、深めた中身を作った日時と候補の id は、`GET /api/deepen` から取る
- 版は、利用者キー（ログインした人を見分ける値）ごとに 1 件にまとめて保存する。「全部消す」で消え、最後に使った日から 30 日で自動で消える（[00-common.md](00-common.md) の「データ」）
- 版は、読んだときから変わっていないときだけ書く。ほかの画面が同じ中身の版を先に書いていたら、増やさない。これより新しい時点の中身で先に版を書いていたら、古い中身を上に積まない（Claude の判断）
- ログの決まりは [00-common.md](00-common.md) の「データ」に従う。レポートの中身はログに書かない

## 受け入れ基準

1. report-1（一つにまとめて示す）: レポートに、確かめた力と根拠、まだ確かめていないこと、5 つの記録、選んだ案、仕事の場面での考え方、最初の一歩が、決めた順に並ぶ。本人が外した力は出さない。できることの欄が空で、本人が見立てを外しているときは、外した見立てはここに出していないと添える。読み込めなかったときも、ホームへの道を出す。確かめ方: 単体テスト（一つの処理だけを取り出して確かめるテスト）、結合テスト（裏側を丸ごと立ち上げて API を呼ぶテスト）、画面のテスト
2. report-2（直す、保留する、次の一歩を選ぶ）: 欄ごとに直す画面への道があり、レポートから保留でき、深めた中身があれば一歩を選ぶか書いて保存できる。確かめ方: 画面のテスト
3. report-3（版を残す）: 中身が変わったら版が一つ増え、前の版と、変わった欄が残る。前の版には根拠の本人の言葉を残さない。場面を飛ばしたら、飛ばしたやりとりのあいだに作った版を残さない。確かめ方: 単体テスト、結合テスト、画面のテスト
4. report-4（決めつけない）: 画面の文言とコードが組み立てる文に、使わない言葉と、言い切りと順位の言葉（[00-common.md](00-common.md) の「言葉」）がなく、選んだ案は「あなたが選んだ案」として書く。本人の言葉と、05 options（仕事の選択肢）と 06 deepen（選んだ案を深める）で照らし合わせた AI の文は数えない。確かめ方: 単体テスト、画面のテスト
5. report-5（保留しても開ける）: 案を保留していても、まだ選んでいなくても、話し終えた場面があればレポートを開ける。確かめ方: 結合テスト、画面のテスト
6. report-6（話を足したら作り直す）: レポートのあとにまた話して記録が変わったら、次に開いたときに版が一つ増える。確かめ方: 結合テスト

## やらないこと

- AI でレポートの文を書くこと。まとめるだけにする
- PDF への書き出し（P2。時間が残れば足すもの）
- 前の版に戻すこと。前の版は見るだけにする
- レポートをほかの人と共有すること

## 評価との対応

AI を呼ばないので、架空エピソード集での評価はない。[6-quality.md](../prd/6-quality.md) の「本人の代わりに決める」に当たる言い方がないことは、画面の文言とコードが組み立てる文をテストで確かめる（common-1（使わない言葉を出さない）と report-4（決めつけない））。

- コードが決めた言葉（先頭の文、「あなたが選んだ案」、深めていないときの文など）は、開発者が確かめる項目として残す
