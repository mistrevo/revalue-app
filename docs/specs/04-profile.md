# 04 profile（5 つの記録）

## 目的

話して確かめた力と、本人の好み、やりたいこと、生活の条件、大事にしたいことを、混ぜずに 5 つの記録として残す。05 options（仕事の選択肢）は、この 5 つを使って出す。

どの記録も本人が直せる。このまとまりでは AI を呼ばない。好みとやりたいことも、本人が選ぶか書く（下の「やらないこと」）。

達成するユースケースは「自分を整理する」（[2-usecases.md](../prd/2-usecases.md)）。言葉とデータの決まりは [00-common.md](00-common.md) にある。

## 振る舞い

### 5 つの記録

意味は [5-information.md](../prd/5-information.md) の「5 つの記録」に従う。

| 記録 | 中身 | 入り方 |
|---|---|---|
| できること | 力の名前と根拠の本人の言葉。「あなたの話から見えた力」と「確かめ中」を分けて示す | 03 validate（確かめる）の力の状態から作る。ここでは保存しない |
| 好み | 合うやり方や環境 | 問いに、選ぶか書いて答える。5 つまで足せる（Claude の判断） |
| やりたいこと | やってみたいこと、これから目指したいこと | 問いに、選ぶか書いて答える。5 つまで足せる（Claude の判断） |
| 条件 | 使える時間帯、週あたりの時間、家でできることだけか外にも出られるか、月の収入の目安 | 本人が選んで入れる |
| 主体性 | 自分で選び、動き出すときに大事にしたいこと | 本人が書く。AI は推し量らない |

- 5 つは別々に示す。できること以外の 4 つは、別々に保存する。ある記録の言葉を、ほかの記録に写さない（profile-1（5 つを分けて残す））
- 好みとやりたいことの項目は、選んだか書いたかを持つ。画面では、選んだ項目に「（選んだ答え）」と添える（Claude の判断）

### できること

03 validate（確かめる）が持つ、利用者ごとの力の状態から作る（profile-2（できることは根拠とつなぐ））。

- 根拠ありの力（力ごとに決めた 3 つの核となる行動が、一つの出来事の中でそろった力）: 力の名前と根拠の本人の言葉を、「あなたの話から見えた力」として示す
- 要確認の力（根拠のある行動はあるが、3 つはそろっていない力）: 「確かめ中」として分けて示し、根拠の本人の言葉も添える
- 未確認の力（まだ聞けていない力）: 出さない。根拠のないものを、できることに入れないため
- 本人が外した力: 出さない。外した力があるときだけ、「外した見立ては、ここには出していません。見えた力の画面で戻せます。」と添える（Claude の判断）
- 見えた力も確かめ中の力も外した力もないときは、「まだありません。話した出来事から見えてきたら、ここに出ます。」と出す。外した力しかないときは、外した注記だけを出す（Claude の判断）
- 根拠の言葉は、[00-common.md](00-common.md) の「言葉」の見せ方で出す
- 直すときは、見えた力の画面（外す・戻す）か、その話の「読み取りを直す」を使う。この画面には、その 2 つへの道を置く（力ごとに「この話を開いて直す」、欄の下に「見えた力の画面で直す」）

### 聞く順番

記録の画面の上に、「いま聞きたいこと」を一つだけ出す。まだ答えていない問いのうち、次の順で最初のものを出す（profile-5（好みとやりたいことを一つずつ聞く）。Claude の判断）。どれも、仕事の選択肢より先に聞くための問い（profile-3（条件を先に聞く））。

1. 好み
2. やりたいこと
3. 条件
4. 主体性

- 4 つの問いがどれも済んだら（答えたか、あとにすると選んだら）、「いま聞きたいこと」は出さない
- 好みとやりたいことには「いまは決めない」、主体性には「いまは書かない」を置く（Claude の判断）。選んだら、その問いは済んだものとして扱い、記録の欄には、好みとやりたいことは「まだ決めていません」、主体性は「まだ書いていません」と出す。あとから記録の欄で足せる
- 条件には、あとにする道を置かない。仕事の選択肢に要るため。入れずに画面を離れることはできる
- 仕事の選択肢をいつ出せるかは、05 options（仕事の選択肢）が、この記録を読んで決める

### 好みとやりたいことの問い

問いと選択肢は、コードが決めた言葉にする（Claude の判断）。どれも本人の力を値踏みする言い方にしない。選択肢は 3 つと「自分で書く」。言葉は裏側の 1 か所（`ProfileText.cs`）に置いて API で渡し、使わない言葉の一覧とテストで照らし合わせる（03 validate（確かめる）の `AbilityText.cs` と同じ扱い）。

| 記録 | 問い | 選択肢 |
|---|---|---|
| 好み | どんな進め方や環境が、自分に合っていると思いますか？ | 自分のペースで進められる / 人とやりとりしながら進められる / 決まった手順がある |
| やりたいこと | これからやってみたいことや、目指したいことに近いものはありますか？ | 家にいながらできることを始めたい / 人の役に立つことをしたい / 新しいことを覚えたい |

- 選んだ答えは、選択肢の言葉のまま保存する。書いた答えは 1〜100 文字（Claude の判断）
- 選択肢でない言葉を「選んだ」として送ってきたら断る

### 条件

本人が選んで入れる（profile-3（条件を先に聞く））。数で比べられるよう、どれも決まった選択肢から選ぶ（Claude の判断）。

| 項目 | 選択肢 |
|---|---|
| 使える時間帯（いくつでも） | 朝（9 時まで） / 日中（9〜15 時） / 夕方（15〜18 時） / 夜（18 時から） |
| 週あたりの時間 | 週 3 / 5 / 10 / 15 / 20 / 30 / 40 時間くらいまで |
| 場所 | 家でできることだけ / 外に出ることもできる |
| 月の収入の目安 | 月 1 / 3 / 5 / 8 / 10 / 15 / 20 万円くらい / まだ決めていない |

- 時間帯は 1 つ以上選ぶ。週あたりの時間と場所は必ず選ぶ。収入の目安は「まだ決めていない」を選べ、初めて入れるときは「まだ決めていない」から始める（Claude の判断）
- 選び終えるまでは保存できず、何を選べば保存できるかを添える（Claude の判断）
- 収入の目安は、仕事の選択肢で比べて示すためだけに使い、絞り込みには使わない（[4-rules.md](../prd/4-rules.md)、[5-information.md](../prd/5-information.md) の「職種と業務のデータ」）

### 主体性

- 欄の見出しは「自分で選び、動き出すときに大事にしたいこと」にする（[5-information.md](../prd/5-information.md)）
- 本人が書く。0〜500 文字（Claude の判断）。AI は推し量らない。欄に添える例も、一つの答えに誘わない言い方にする（profile-6（主体性は本人が書く））
- 空で保存しても、「いまは書かない」を選んでも、記録の欄には「まだ書いていません」と出す

### 直す

- 好みとやりたいことは、項目ごとに消せる。記録の欄から、問いの選択肢を選ぶか書いて足せる。もう入っている選択肢は、足すときに出さない（Claude の判断）
- 条件と主体性は、記録の欄からいつでも書き直せる
- できることは、上の「できること」のとおり、見えた力の画面とその話から直す（profile-4（本人が直せる））

### 画面

- `/profile` に「5 つの記録」の画面を置く。ホームから入れる
- 画面の先頭で、話した言葉と本人の答えをもとにしていること、どれも直せることを一文で伝える
- 「いま聞きたいこと」（上の「聞く順番」）の下に、5 つの記録をこの順で並べる: できること、好み、やりたいこと、条件、主体性
- 状態の呼び名、点数、順位と、使わない言葉（[00-common.md](00-common.md) の「言葉」）は出さない
- 保存に失敗したら、その欄に穏やかな言葉を出し、入れた内容は入力欄に残す
- 幅 375px と 1280px で、横にはみ出さない

### API

どれもログインと了解が要る（[01-foundation.md](01-foundation.md)）。AI は呼ばないので、送信回数の上限は数えない（Claude の判断）。

| API | 振る舞い |
|---|---|
| `GET /api/profile` | 5 つの記録と、どの問いに答えたか、問いの言葉と選択肢を返す。できることは、そのときの力の状態から作る |
| `PUT /api/profile/preferences` | 好みの項目を、送った並びに置き換え、好みの問いに答えたことにする。0〜5 項目。各項目は、選んだもの（選択肢の言葉）か、書いたもの（1〜100 文字） |
| `PUT /api/profile/wants` | やりたいことを、好みと同じ形で置き換える |
| `PUT /api/profile/conditions` | 条件を置き換える。選択肢にない値は 400（送られた中身が正しくないと返す応答） |
| `PUT /api/profile/agency` | 主体性を置き換え、主体性の問いに答えたことにする。0〜500 文字。空なら書いていないことにする |

- 形の合わない要求は 400 にし、何も保存しない
- 好み、やりたいこと、条件、主体性は、利用者キー（ログインした人を見分ける値）ごとに 1 件にまとめ、記録ごとに別の欄に保存する。「全部消す」で消え、最後に使った日から 30 日で自動で消える（[00-common.md](00-common.md) の「データ」）

## 受け入れ基準

1. profile-1（5 つを分けて残す）: 好み、やりたいこと、条件、主体性は、別々の欄に保存され、API でも別々に返る。ある記録を置き換えても、ほかの記録は変わらない。「全部消す」で 5 つの記録も消える。確かめ方: 結合テスト（裏側を丸ごと立ち上げて API を呼ぶテスト）
2. profile-2（できることは根拠とつなぐ）: できることには、根拠ありの力が根拠の本人の言葉と一緒に入る。要確認の力は確かめ中として分けて入り、未確認の力と外した力は入らない。確かめ方: 結合テストと画面のテスト
3. profile-3（条件を先に聞く）: 条件の欄で、時間帯、週あたりの時間、場所、収入の目安を選んで入れられる。選択肢にない値は断る。仕事の選択肢より先に聞くことは、05 options（仕事の選択肢）で確かめる。確かめ方: 結合テストと画面のテスト
4. profile-4（本人が直せる）: 好み、やりたいこと、条件、主体性を、記録の欄から書き直せる。できることには、見えた力の画面とその話を直す道がある。確かめ方: 結合テストと画面のテスト
5. profile-5（好みとやりたいことを一つずつ聞く）: 「いま聞きたいこと」には、まだ済んでいない問いが一つだけ、好み、やりたいこと、条件、主体性の順で出る。好みとやりたいことの問いには、選択肢 3 つと「自分で書く」「いまは決めない」がある。「いまは決めない」を選ぶと、次の問いへ進み、記録の欄に「まだ決めていません」と出る。確かめ方: 画面のテスト
6. profile-6（主体性は本人が書く）: 主体性は本人が書いた言葉だけを保存し、アプリが中身を作らない。確かめ方: 結合テストと画面のテスト

## やらないこと

- 会話から好みとやりたいことを AI が推し量って足すこと。PRD（[5-information.md](../prd/5-information.md) と profile-4（本人が直せる））は「足せる」として、推し量った項目の見せ方も決めているが、この版では作らず、P1（試用のあとに足すもの）に回す。話から好みを読み取ると「性格診断」に見えやすく、本人が選ぶ・書くだけでも 5 つの記録はそろうため。項目が持つのは、選んだか書いたかだけにする（Claude の判断）
- 仕事の選択肢を出すかどうかの判断。05 options（仕事の選択肢）で、この記録を読んで決める
- 5 つの記録の履歴。直した前の中身は残さない（Claude の判断）

## 評価との対応

このまとまりは AI を呼ばないので、架空エピソードの評価は足さない。言葉の決まりは、文言のテストで確かめる。

- 問いと選択肢、記録の画面の言葉に、使わない言葉（[00-common.md](00-common.md)）が入らない
- 問いと選択肢（コードが決めた言葉）は、AI 同士の判定だけで確定しない。開発者が確かめる項目として残す
