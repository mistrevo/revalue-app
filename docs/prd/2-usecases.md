# 2. ユースケース — 価値がどこで生まれるか

## 利用シーン（Claude の判断）

- 子どもが寝たあとや用事のすき間に、スマホで 10〜15 分ずつ話す
- 何日かに分けて、前回の続きから話す
- 気になる仕事を一つ選び、可能性レポートで次の一歩を決める
- 決めた一歩を、家族やキャリア相談の場で話す
- 決めた一歩のあと、別の日にまた開き、その後のことや別の日の出来事を話す

## ユースケース

| ユースケース | 利用者がすること | 生まれる価値 |
|---|---|---|
| 始める | 保存するもの、保存期間、いつでも消せることを知り、了解して始める | 安心して話せる |
| 経験を話す | AI の問いに、選択肢か自由な言葉で答え、最近の、気持ちが動いた具体的な一日を話す。途中でやめて、続きから話す | 気づく |
| 力を確かめる | この話から見えた力、根拠になった自分の言葉、もう少し聞かせてほしいことを見る。違っていれば直し、違う見立ては外す | 気づく |
| 自分を整理する | 好みとやりたいことを一つずつ答え、条件と主体性を書く。5 つの記録（できること、好み、やりたいこと、条件、主体性）を見て、直す | 気づく、思い立つ |
| 仕事の選択肢から選ぶ | 「選ぶ」「組み合わせる」「創る」の 3 枚のカードを見て、一つ選ぶ、保留する、または自分で考えた仕事を書く | 思い立つ |
| 選んだ案を深める | 選んだ案の業務ごとに、使える力と、まだ確かめていないことを見る。その仕事の場面で、仮の状況ならどうするかに答える。最初の一歩の候補を見る | 動ける |
| 次の一歩を決める | 可能性レポートを見て、直す、保留する、次の一歩を選ぶか自分で書く（1 つでも複数でもよい）。案を保留していてもレポートは開ける | 動ける |
| 別の日にまた話す | 別の日に開き、選んだ一歩のその後か、別の日の出来事を話す。同じ力が別の話にも出てきたら、そう示される。思い出したければ、日を選んでカレンダーに入れる。また話さなくてもよい | 気づく、動ける |
| やめる | いつでも全部消す。使わなければ自動で消える | 安心して話せる |

## 誰にどのユースケースを届けるか

| 人 | 使うユースケース | ハッカソン期間の使い方 |
|---|---|---|
| 利用者 | すべて | 当事者 3〜5 人に話を聞き、使ってもらう |
| 審査員 | すべて。価値を届ける相手ではない | README の手順で、自分の Google アカウントでログインし、架空の人になりきって一から使う |
| 先輩メンター | なし | 架空のサンプルデータとしてだけ出す（優先度 P2。時間が残れば足す） |

## デモの筋（3 分の動画）

主人公は、育児のため 5 年間離職した架空の女性。名前も架空のものを付ける。週 10 時間、在宅で働きたいと考えている。

1. 冒頭で、課題を一文と数字（第 1 子の出産の前後で、およそ 5 人に 1 人が仕事を続けていない）で示す。「私には何もない」と言う主人公に、AI が受け止めてから、最近の、気持ちが動いた日を聞く
2. 話から拾った行動を根拠に、3 つの力の状態と、まだ聞けていないことが出る
3. 5 つの記録が、混ざらずに別々に残る
4. 「選ぶ」「組み合わせる」「創る」の 3 枚のカードが、同じ重さで並ぶ
5. 主人公が 1 枚選ぶと、その案だけを深め、業務ごとに使える力とまだ確かめていないことを示す。その仕事の場面での仮の問いに答え、考え方の傾向が残る
6. 可能性レポートで、主人公が次の一歩を選ぶ
7. 別の日に開くと、選んだ一歩のその後から話が始まる。同じ力が別の話にも出てくると、「2 つの話に出てきた力」と示される（Claude の判断。動画の時間が足りなければ削る）
8. 同じ話を汎用の AI に入れた結果と並べ、違いを見せる。最後に、架空エピソード集（架空の利用者が話す出来事の例。[6-quality.md](6-quality.md)）で、汎用の AI と比べた数字を見せる。試用の数や感想が取れていれば、それも見せる（Claude の判断）
