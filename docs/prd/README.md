# PRD — RE:VALUE（リバリュー）

> **素案（2026-11-02 更新）**。開発者が読んで確定する。Claude が仮に決めたところには「（Claude の判断）」と書いた。開発者に決めてほしいことは、最後の「決めていないこと」にまとめた。

## 何を作るか

育児などでキャリアを中断した人のための Web アプリ。AI が聞き手になり、人生の経験を具体的な出来事として引き出す。本人の言葉を根拠に、3 つの力（見立てる力、調整する力、優先順位をつける力）を確かめ、仕事の選択肢を広げる。どの仕事に進むかは本人が選び、最初の一歩を決める。AI は仕事を決めない。

> キャリアには空白があっても、人生に空白はない。

ハッカソンのテーマ 2「本来、誰にでも届くべきものを。」に応える。

## 製品の芯（ぶらさない）

1. **根拠のない力は出さない**: 力ごとに、核となる行動を 3 つ決めている（[4-rules.md](4-rules.md)）。その 3 つが一つの具体的な出来事の中ですべて確かめられたときだけ「根拠あり」とし、本人の言葉を添える
2. **突き放さない**: 「根拠なし」「不得意」とは言わない。足りないときは、足りない行動だけを聞き返す
3. **AI が聞き手になる**: 利用者は質問を考えなくてよい。最近の具体的な一日を尋ね、毎回受け止めてから一つだけ聞く
4. **条件の中で選択肢を広げる**: 使える時間と場所の範囲で、収入の目安と比べながら、3 つの道を示す。「選ぶ」は登録した実在の職種、「組み合わせる」は登録した業務の組み合わせ、「創る」は事業のアイデア
5. **本人が選ぶ**: AI の見立てを、採用の判断や適職の断定の代わりにしない。本人が直す、保留する、却下する、自分の案を書く

## 作るときの判断

- 機能の数より、一人の体験を最後まで通すことを優先する。最後とは、確かめた力、選んだ案、最初の一歩をまとめた可能性レポート
- 削るときは、職種の数や見た目の飾りから削る。受け止める言葉、本人が決めること、根拠を示すことは削らない
- 力を確かめることは目的ではない。本人が信じられる発見のための手段
