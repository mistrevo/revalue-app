# 4. 決まり — 力を確かめる物差し、対話、仕事のカード

まとまりをまたいで使う決まり。Spec の `docs/specs/00-common.md` は、ここを元に細部を書く。

## 力を確かめる物差し

見る力は 3 つ。力ごとに、核となる行動を 3 つ決める。

| 力 | 核となる行動 |
|---|---|
| 見立てる力 | ① 変化に自分で気づく ② 判断の手がかりを挙げる ③ いつもの様子や前と比べる |
| 調整する力 | ① 都合の違う 2 者以上が関わる ② 本人から働きかける ③ 代わりの案を出すか、双方の都合を合わせる |
| 優先順位をつける力 | ① 全部はこなせないほど用事が重なる ② 何を先にし、何を後に回すかを具体的に決める ③ 決めた理由や基準がある |

力の状態は 3 つ。

| 状態 | どういうときか |
|---|---|
| 根拠あり | 一つの具体的な出来事の中で、核となる行動が 3 つとも確かめられた |
| 要確認 | 一部だけ確かめられた。または一般論だけで、具体的な出来事がまだない |
| 未確認 | その力にあたる本人の行動が、まだ聞けていない |

- 「根拠なし」「不得意」とは言わない。未確認は「まだ聞けていない」という意味で、力がないという意味ではない
- 結果の良し悪しや、結果を話したかどうかは、確かめる条件にしない
- 根拠になるのは、本人が話した具体的な出来事の中の発言。選択肢を選んだ答えだけでは足りない。本人が話したほかの事実と結びついたときだけ根拠にし、選んだ答えだと分かるように示す（示し方は Claude の判断）
- 仮の場面の問いへの答えは、考え方の傾向として残す。それだけで力の状態を上げない
- 生活の中で確かめたことと、仕事でも発揮できそうかは、別々に持つ
- 本人が訂正したときや、AI の読み違いが分かったときは確かめ直し、いつ、何が、なぜ変わったかを残す
- 力の確かめは、会話の返事を作る処理とは別に行う。確かめの結果だけを取り出して、評価で確かめられるようにする

画面での見せ方（Claude の判断）:

- 状態の呼び名（根拠あり、要確認、未確認）と、核となる行動のチェック表は、画面の前面に出さない。試験のように見えやすいため
- 画面では「この話から見えた力」「もう少し聞かせてほしいこと」「まだ聞けていない力」のような言葉で示す。「要確認」の力をカードや可能性レポートで使うときは「確かめ中」と示す

## 対話の決まり

- 毎回、受け止める一文、本人の行動を映し返す言葉、問い一つ、の順で返す。問いだけを返さない
- 答え方は、選択肢 3 つと「それ以外」、自由に書く欄。自由に書く欄はいつも出す
- 「分からない」も答えとして受け止める。つらい話は飛ばせる
- 一つの場面は 5〜8 往復を目安にする。途中でやめても、続きから話せる
- 足りない行動の聞き返しは、場面を話している会話の中で行う
- 大げさな褒め言葉で埋めない。本人がしたことを具体的に映し返す
- 家族の病気や症状の詳しいことは聞かない。本人がしたことに焦点を当てる（Claude の判断）
- 本人の心身の不調、家庭内の暴力、死にたいという言葉が出たら、受け止め、公的な相談窓口を一つ示す。その話は力の確かめに使わない（Claude の判断）

問いは 3 種類。

| 問い | 何を聞くか | 力を確かめるときの扱い |
|---|---|---|
| 経験の問い | 実際にしたこと | 根拠になる |
| 仮の場面の問い（状況判断質問） | 選んだ案の仕事の場面で、仮の状況ならどう考え、どうするか | 考え方の傾向として残す。根拠にはしない |
| 模擬業務 | 限られた課題を実際にやってみる | 優先度 P2。扱いは作るときに決める |

## 仕事のカードの決まり

| カード | 中身 | AI が書いてよいこと |
|---|---|---|
| 選ぶ | 登録した実在の職種 | 本人の力に合う理由。職種は作らない |
| 組み合わせる | 登録した業務を 2〜3 個組み合わせた働き方 | 役割の名前と、本人の力に合う理由 |
| 創る | 「誰の、どんな困りごとを、本人のどの力で、どの条件で」の形の事業のアイデア | 中身すべて。ただし本人の根拠を引けなければ出さず、需要はまだ確かめていないと必ず示す |
| 本人が書いた仕事 | 本人が自分で考えた仕事 | 深めるときの業務の見立て。本人が直せる。登録した職種のようには見せない |

- 3 枚は同じ重さで並べ、順位を付けない
- 本人は、選ぶ、保留する、自分の仕事を書く、のどれでもできる。本人の希望と AI の案が違えば、両方残す
- 深めるのは、本人が選んだ 1 案だけ
- どのカードも、本人の時間と場所の条件の範囲に収める。収入は、本人の目安と比べて示す。「創る」は需要をまだ確かめていないので、収入の数字は示さない（Claude の判断）
- カードの理由には「要確認」の力も使える。そのときは「確かめ中」と示す
