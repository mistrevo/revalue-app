# ns-motion-studio

Anthropic の Claude Motion（claude.ai の機能）とは別物です。本プラグインは Claude Code 上で、コードで動画を描いて書き出します。

紹介動画と、制作の流れを実際の確認ページで見せる紹介ページ: [docs/intro/index.html](docs/intro/index.html)（GitHub では https://github.com/nextscape/ns-skills/tree/main/plugins/ns-motion-studio/docs/intro 。index.html をブラウザで開く）

製品・サービス紹介、解説、マニュアル、ロゴ、告知、採用など、種類を問わず**モーショングラフィックスの動画**を、ブリーフィング（聞き取り）から完成の MP4 まで作るプラグイン。動画や ffmpeg に詳しくなくても、チャットと HTML の確認ページだけで進められる。動画生成モデルは使わず、シーンを HTML で描いて時刻ごとに撮り、MP4 にまとめる。同じ入力からは同じ動画が出るので、一部だけの直しも安全にできる。

## できること

- ブリーフィング（聞き取り）、スタイル決め、絵コンテとテロップ、ラフ版の確認を経て、完成の MP4 を書き出す。工程の長さは、お試し・サンプル・本番の3コースから選べる
- 効果音をコードで合成して付ける。ナレーション（VOICEVOX か Gemini）と BGM（Gemini か持ち込み）も付けられる
- 書き出したフレームでの自動点検（文字のコントラスト、点滅、文字の最短表示時間、音量など）
- できた動画の一部だけの修正（「カット3のロゴをもっとゆっくり」のような指摘を数値の変更に直して再書き出し）
- 表現や演出は、使う人の意図に合わせて既定から外せる（点滅、ロゴの変形、薄く敷く文字なども選べる）。外したことは確認ページに一覧で出る
- 数値・社名・事例・製品の機能は、利用者が渡した事実だけを使う。足りなければ偽物を描かず、止めて頼む

## 対象の動画

種類は決めていない。ブリーフィングで「誰に見せ、見た後どうなってほしいか」を聞き、組み合わせて使える構成の型（課題 → 解決 → 証拠、手順、図で組み上げる解説、告知、印象づけ、物語、一覧・紹介）と、似た依頼の作例（ロゴリビール（ロゴを印象的に見せる短い動画）、製品ローンチ、製品・サービス紹介、技術解説、製品マニュアル、会社紹介）を選択肢として示して組み立てる。fps の既定は 30 で、動きの速い動画は 60 を提案する。

スライドや既存資料をそのまま動画にする依頼は対象外（スライドを動画にする別のスキルを使う）。既存の動画ファイルの編集・変換、Web ページのアニメーション、実写風の映像や人物の生成も対象外。

### 比率

| 比率 | 解像度 |
|---|---|
| 16:9 | 1920×1080 |
| 9:16 | 1080×1920 |
| 1:1 | 1080×1080 |
| 4:5 | 1080×1350 |

比率を増やすときは切り抜きではなく、比率ごとにレイアウトを組み直す。ラフ版は 960×540 相当（16:9。ほかは長辺 960）、30fps。

## 1本は5分まで（理由）

5分を超える動画で品質と再現性を保ち、部分的な修正に応えるには、本格的な仕組みが別に必要になる。

- 章をまたぐ構成管理
- 差分の書き出し
- 全体を通した点検

本プラグインではそこまでは作らない。長い内容（長いマニュアルなど）は、5分以内の章ごとの連作として扱うよう、ブリーフィングで提案する。

## インストール

```bash
/plugin marketplace add nextscape/ns-skills
/plugin install ns-motion-studio@nextscape
```

## 使い方

```
/ns-motion-studio:make-video 新製品の紹介動画を作りたい
```

作りかけの動画の続きも、同じ呼び出しで制作フォルダを指せば再開できる。

### コース（工程の長さ）

ブリーフィングの最初に、どこまで作り込むかを選ぶ。途中で本番に切り替えることもでき、作ったものはそのまま引き継ぐ。

| コース | 向く場面 | 使う人の確認 |
|---|---|---|
| お試し | とりあえず試したい | 完成（納品）の1回だけ |
| サンプル | 短時間で見本が欲しい | 書き出しの前の「構成の確認」と、完成の2回 |
| 本番 | 本番で使う | 下の流れの関門をすべて |

自動点検は、どのコースでもすべて行う。

### 1回の進み方（本番）

1. **準備。** 制作フォルダを決め、必要な道具を確かめる
2. **ブリーフィング。** 目的・視聴者・使う素材などを聞き取る。**関門1**: HTML の確認ページでブリーフィングの内容を承認する
3. **スタイル決め。** 候補の静止画から選ぶ（確認ページ）
4. **絵コンテ。** カットの並びとテロップを決める。**関門2**: 確認ページで承認する
5. **音と実装。** 効果音・ナレーション・BGM を整え、シーンを描いて自己点検する
6. **ラフ版。** 低い解像度で書き出して見てもらう。**関門3**: 代表のスチルとラフ版を確認ページで承認する
7. **仕上げと納品。** 書き出しにかかる時間の見込みを伝えてから、全品質で書き出す。納品確認ページで最終の確認を取る
8. **部分修正。** 指摘は確認ページの「指摘をまとめてコピー」を貼るか、チャットに書く。直したカットだけ再書き出しする

どの関門でも前の段階に戻れる。承認なしに次の関門がある段階へは進まない。

### 成果物の置き場所

利用者の作業フォルダの下の制作フォルダに出る（プラグインのインストール先には書かない）。

| 場所 | 中身 |
|---|---|
| `out/` | 完成版 `<題名>_<比率>.mp4`、ポスター画像、ループ版（展示会向けのとき）、再現手順 |
| `reviews/` | 各関門の確認ページ、指摘の記録、使った素材と権利の一覧（`rights.md`） |
| `assets/`、`audio/` | 利用者が渡した素材、ナレーションや BGM の音声 |
| `src/scenes/` | シーンの HTML |
| `project.json`、`timeline.json` | 進み具合と、テロップ・ナレーション・効果音の正本 |

制作フォルダには `.gitignore` も置く（既にあれば書き換えない）。書き出した動画（`out/*.mp4`）と音声（`audio/` の wav）、作り直せる中間データ（シーンごとの書き出し `out/.scenes/`、点検の記録 `reviews/.check-cache/`、確認用のコマ画像 `reviews/frames/` など）は git に入らない。動画と音声は git の外で渡す・残す。`project.json`、`timeline.json`、シーン、文書、指摘や権利の記録は git に入る。

## 必要なもの

- **Node.js 22.12 以上。** `node --version` で確かめ、入っていなければ https://nodejs.org/ から LTS 版を入れる（Windows なら `winget install OpenJS.NodeJS.LTS`、Mac なら `brew install node`）。会社のパソコンで管理者の許可が要るときは、情報システムの担当に頼む。入れたら Claude Code を開き直す。スキルは `node` が無ければ入れ方を案内して止まる
- **そのほかはスキルが案内して入れる。** 描画用のブラウザ（puppeteer）と動画をつなぐ ffmpeg は、初回に、試した版（puppeteer 25.15.0、ffmpeg-static 5.3.0、ffprobe-static 3.1.0）を `~/.claude/ns-motion-studio/tools/` へ入れる（システムに ffmpeg があればそれを使う）。npm とネットワークが要る。puppeteer のブラウザ本体も同じ置き場の `chrome/` に入る（この版より前に入れた環境では `~/.cache/puppeteer` のものをそのまま使う）
- **前提モデルは Opus 5.5 以上。** 未満なら、品質を保証できない旨を伝えたうえで、続けるかどうかを利用者に決めてもらう
- 道具を入れられない環境では、絵コンテまでを進めて Claude Motion に引き継ぐ手順に切り替わる

## 外部 API（任意）

ナレーションの VOICEVOX（無料、ローカル）と、Gemini（読み上げ・BGM の作曲）は**どちらも任意**。効果音だけの動画なら、外部サービスは要らない。

Gemini を選ぶときは、使う前にスキルが次を案内し、了承を得てから使う。キーは環境変数 `GEMINI_API_KEY` で受け、制作フォルダには書かない。

- 課金設定済み（有料）のプロジェクトのキーを使う。無料枠では、送った内容が Google の製品改善に使われ、人が読むこともある
- 未公開の製品情報、顧客名、個人情報を含む原稿を送るかどうかは、利用者が判断する。迷う場合は VOICEVOX（ローカル）を使う
- 費用がかかる。BGM は1曲 $0.08、読み上げは文字量に応じて課金される
- 生成音声には透かしが入る。他の利用者に似た曲が出る可能性があり、補償は確認できていない
- 特定のアーティストの声、既存曲の歌詞、実在の人物の声は指定しない
- AI で生成した音であることの表示は、社内のルールに従う

VOICEVOX を使うときは、クレジット表記（「VOICEVOX:キャラクター名」）が必要。キャラクターごとに利用規約があるので、使える声は、企業の動画（商用）でも申請・連絡なしにクレジットだけで使えると規約がはっきりしているキャラクター（四国めたん、ずんだもん、九州そら、中国うさぎ、中部つるぎ、冥鳴ひまり、雨晴はう、満別花丸。2026-10-23 に確認）に絞ってある。既定は四国めたん（話す速さ 1.1、抑揚 1.2）。使った音源の出典とライセンスは `reviews/rights.md` に記録される。
