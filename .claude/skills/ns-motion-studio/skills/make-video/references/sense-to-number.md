# 感覚語の翻訳表

利用者の指摘は、たいてい感覚の言葉で来る（「もたつく」「AIっぽい」）。そのまま「いい感じに直す」と、別の場所が崩れるか、何も変わらない。指摘を受けたら、この表で**数値の変更**に翻訳し、何をどれだけ変えたかを利用者に返す。

## 使い方

1. 指摘がどのカットの、何秒あたりのことかを確かめる（確認ページの指摘はカット番号と時刻が付いている）。分からなければ、全体の話か、特定のカットの話かを聞く。
2. 下の表で、当てはまる行の「まず疑うこと」を、そのカットのコードと書き出したフレームで確かめる。当てはまったものだけを直す。全部を一度に変えない（1回の修正で変える軸は2つまで）。
3. 直した数値を、変更前と変更後で書いて返す（例: 「カット3 の見出しの入場を 900ms から 600ms に、退場を 900ms から 350ms にしました」）。
4. 直したカットだけを書き出し直し、遷移の前後のフレームを見てから確認に回す。

数値の既定値は `motion-rules.md`、何も言われないときに避ける癖は `banned.md` にある。翻訳した結果がその癖に当たるなら、まず別の直し方を採る（「ポップに」を「全部を跳ねさせる」と訳さない）。使う人がその癖そのものを望んでいると分かれば、`style.md` の「既定から外すこと」に書いて使う。

## 翻訳表

| 言われたこと | まず疑うこと | 直す数値 |
|---|---|---|
| **ポップに** | テンポが遅い。色が沈んでいる。見せ場に「着地」がない | 入場を 1 段階短く（ヒーロー 800ms → 600ms、移動 400ms → 250ms）。ずらしを詰める（単語 100ms → 60ms、項目 80ms → 40ms）。小さな印（バッジ、チェック）1〜2個だけを、ばね stiffness 170・damping 19（減衰比 0.73）か `ms.ease.outBack` にする。アクセント色の彩度を上げ、面積を画面の 10〜15% まで広げる。BGM があれば 120〜128BPM に。着地に `pop` か `click` の効果音を 1 フレーム後に置く。文字やカードは跳ねさせない |
| **もたつく** | 退場が長い。前の要素が終わるまで次が待っている。カットの間に空の画面がある。止まっている時間が長すぎる | 退場を入場の 50〜60% にし、`ms.ease.inQuart` に変える。次の要素の開始を、前の要素が 30〜50% 進んだところまで前に出す。カット間の空の画面を 0.1 秒以下にする（次のカットの入場を前のカットの退場に重ねる）。ホールドを「最短の表示時間 + 0.5 秒」以内に縮める（締めを除く）。入場の曲線を `ms.ease.outQuint` から `ms.ease.outExpo` に（最初の速さが増す） |
| **ごちゃつく** | 同時に動く物が多い。1画面の文字が多い。アクセント色が散っている。余白が少ない | 同時に動く要素を3つまで、ヒーローは1つに。4つ目以降はヒーローが 50% 進むまで待たせる。1画面の文字のかたまりを3つまで、テロップは1画面1文に（溢れた分はカットを分ける）。アクセント色は「意味のある1か所」だけに戻す。余白（何も置かない面）を画面の 40% 以上にする。視差の層を3枚以下に。飾りの要素（線、点、模様）を半分に減らす |
| **AIっぽい** | 全要素が同じ長さ・同じ動きで出る。紫系のグラデーション、グロー、ガラス風。全カットが中央揃え。常に何かがズームしている。どこかで見た言い回し | `banned.md` を上から順に当てはめ、当たった癖を消す。入場を要素ごとに変える（主役はマスク、補足は 0.96 → 1.00 の拡大、ラベルは不透明度だけ）。長さを3段階に散らす（例: 700ms / 400ms / 180ms）。色を `style.md` のパレットだけに戻す。中央揃えのカットを半分以下にし、左揃えの格子に載せる。2% の寄りは止まっているカットだけに。言い回しの直しは原稿の変更なので、利用者に案を見せて確かめる |
| **安っぽい** | 跳ねる。行き過ぎが大きい。直線で動き出す。影や縁取りが太い。色が多い。素材がぼやけている。書体が既定のまま | 跳ねる動きを `ms.ease.outExpo` か、減衰比 0.8 以上のばね（stiffness 100・damping 17）に替え、行き過ぎを 2% 未満にする。動き出し・止まりの直線をやめる。影はぼかし 24px 以上・不透明度 0.25 以下の柔らかいものにし、縁取りは 2px 以下か無しに。色はパレットの3〜4色に絞る。素材を 100% を超えて拡大しない（足りなければ高解像の素材を頼む）。書体を `style.md` の指定に戻し、見出しに `palt` を入れて字間を詰める。文字の太さを 3 段階以内に |
| **固い** | すべてが同時に始まり同時に止まる。直線で動く。止まった絵が長い。奥行きがない | ずらしを入れる（単語 60〜120ms、項目 40〜80ms）。次の要素を前の要素の 30〜50% で始めて重ねる。直線をやめて `ms.ease.outExpo`（入場）と `ms.ease.inQuart`（退場）に。ばねの減衰比を 0.8〜0.85 から 0.75 に下げる（stiffness 100 なら damping 16〜17 → 15。行き過ぎが見える側なので部品だけに）。主な動きが止まって 1.5 秒を超えるカットに 2% の寄りを付ける。カメラが動くカットに視差（1.0 / 0.5 / 0.2）を付ける |
| **速すぎる** | 文字の表示時間が足りない。ずらしが短すぎて同時に見える。カットが短すぎる。情報が多すぎる | 自動点検の `hold` の結果を見て、全テロップを「文字数 ÷ 5 + 0.5 秒」以上にする。入場の長さを 1.3 倍に（帯の上限まで）。ずらしを帯の上限へ（単語 120ms、項目 80ms）。1カットを 1.5 秒以上に（拍に合わせて刻む連続のカットを除く）。BGM の BPM を 10〜20 下げる。それでも足りなければ、情報を減らすか、尺を伸ばすかを利用者に選んでもらう（尺を伸ばすと関門 1 の長さが変わる） |
| **地味** | 見せ場がない。大きさの差がない。色の役割がない。全カットが同じ強さ | 最大の見せ場を1つ決め、そこだけヒーローの長さ（600〜900ms）、0.92 → 1.00 の拡大、アクセント色、`hit` か `chime` の効果音を集める。見出しと本文の大きさの比を 2.5 倍以上にする。アクセント色を「変わったもの・答え」に使う。カットの強さに波を付ける（強いカットの前に、静かなカットを1つ置く）。締めに決めのフレームを作り、1.5〜2.0 秒止める。パーティクルやグローを足して派手にはしない |

## 表にない言葉が来たら

次の6つの軸のどれの話かに置き換えて、数値で答える。どれにも置けなければ、該当のフレームを見せて「ここのどこが気になるか」を聞く。

| 軸 | 変えるもの |
|---|---|
| 長さ | 入場・移動・退場の ms、ホールドの秒、カットの秒 |
| ずらし | 単語・項目のずらし幅、次の要素の開始位置（前の何% か） |
| 曲線 | `ms.ease` の5つの使い分け、ばねの減衰比 |
| 量 | 同時に動く数、1画面の文字の数、動く距離、拡大率 |
| 色 | パレット、アクセントの面積と場所、コントラスト |
| 大きさ | 文字の大きさの比、余白の割合、主役の面積 |

よくある言い換えの例:

- 「重い」「どんより」 → 長さ（短く）と曲線（`ms.ease.outExpo`）。暗い色が多いなら色。
- 「チカチカする」「目が疲れる」 → 量（同時に動く数）。点滅の自動点検を必ず見る。
- 「読めない」 → 長さ（ホールド）と大きさ（最小の文字サイズ）とコントラスト。
- 「うちっぽくない」 → スタイルの話。`style.md` のパレット、書体、動きの性格に戻って比べる。必要ならスタイル選択に戻る。
