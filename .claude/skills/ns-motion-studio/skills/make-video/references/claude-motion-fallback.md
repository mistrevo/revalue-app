# 道具を入れられないとき（Claude Motion に渡す）

社内のルールやネットワークの都合で、書き出しの道具（[setup.md](setup.md)）を入れられないときの逃げ道。ブリーフィング（段階1）と絵コンテ（段階3）まではこのスキルで進め、その内容から Claude Motion に貼るプロンプトを作って渡す。

## Claude Motion について利用者に伝えること

- Claude Motion は claude.ai の機能（2026-10-08 発表）。**Team と Enterprise 向けのベータ**で、Team プランでは既定でオンになっている。お使いのプランで使えるかは、claude.ai の画面か、社内の管理者に確かめてもらう。
- Claude Code からは呼べない。利用者が claude.ai を開き、作ったプロンプトを貼り、素材のファイルを添付する。
- このスキルの点検（文字の正誤の突き合わせ、はみ出し、点滅、音量）は Claude Motion の出力には効かない。できた動画は、利用者が絵コンテと見比べて確かめる。

## 進め方

1. 逃げ道に切り替えたことを記録する（まだなら）: `node "<プラグイン>/scripts/project.mjs" fallback "<制作>" on`。`project.json` の `settings.fallback` が `claude-motion` になり、再開したときに道具の導入を繰り返さない。
2. 段階1・3は通常どおり進める。スタイル決め（段階2）は静止画を撮れないので、言葉と色見本（`style.md`）だけで決める。段階3では、[storyboard.md](storyboard.md) の下描きのシーンとラフ画を飛ばす（確認ページの各カットに「静止画はまだありません」と出る）。
   - **確認はコースに合わせる。** プロンプトを渡す前に、使う人に一度は中身を確かめてもらう（納品のページはこの逃げ道では作れないため）。
     - 本番: 関門1（briefing）と関門2（storyboard）の承認を取る。
     - サンプルとお試し: 絵コンテの後に構成の確認（`review-page.mjs "<制作>" plan`）を1回作り、承認を取る（お試しでも、このときだけは確かめてもらう）。
3. 下の型でプロンプトを組み、`<制作>/reviews/claude-motion-prompt.md` に書く。
4. ファイルの場所を伝え、claude.ai での手順（新しい会話で Claude Motion を選ぶ → プロンプトを貼る → 「添付する資料」のファイルを添付する）を案内する。

## プロンプトの型

`briefing.md`、`style.md`、`storyboard.md`、`timeline.json` から埋める。文字（テロップ・ナレーション）は `timeline.json` から一字一句写す。

```markdown
# 依頼: <題名> の動画を作ってください

## 目的
<briefing.md の目的>

## 対象者
<briefing.md の見る人。前提知識の程度も>

## 再生場所
<Web サイト／SNS（サービス名）／展示会。音なしで見られるか、ループするか>

## 尺と比率
- 尺: 約 <秒> 秒（各場面の秒数は下の絵コンテのとおり）
- 比率: <16:9（1920×1080）など>
- fps: <30 または 60>

## 一番覚えてほしい一文
「<一文>」

## スタイル
- 色: 背景 `<#16進>`、文字 `<#16進>`、強調 `<#16進>`（文字と背景のコントラストは 4.5:1 以上）
- 書体: <書体名と太さ>
- 動き: <style.md の動きの性格を2〜3行で>
- 避けること: 紫のグラデーション、全要素の同時フェードと浮き上がり、多用されるクロスフェード、意味のないグロー・パーティクル、常時ズーム、<style.md の禁止>

## 絵コンテ
| カット | 秒 | 画（入口 → 出口） | テロップ（一字一句このとおり） | ナレーション |
|---|---|---|---|---|
| 1 | 0:00〜0:04 | <入口の状態> → <出口の状態> | 「<文字>」 | 「<原稿>」 |
| 2 | ... | ... | ... | ... |

## 添付する資料
- <logo.svg>: ロゴ。**描き直さず、このファイルをそのまま使う。** 色を変えない、変形しない
- <screen-01.png>: カット3 で使う製品画面
- <brand-guide.pdf>: ブランドの決まり

## 守ること
- 製品画面、ロゴ、数値、社名、仕様は、添付した資料にあるものだけを使う。無いものを作らない。
- テロップの文字は、上の表のとおり一字一句変えない。
- 文字は画面の端から 5% 以上内側に置き、字幕は字幕の帯（16:9・1:1・4:5 は画面の下 10%、9:16 は下から 20〜30%）に置き、ほかの文字は帯に入れない。9:16 の下 20% は SNS のボタンが重なるので、字幕も含めて文字を置かない。
- 点滅は1秒に3回以下にする。
- 最後の <1.5〜2.0> 秒は止めて、締めの一文とロゴを読ませる。
```

- ナレーションや BGM が要る案件では、Claude Motion で音が付けられるかを利用者に確かめてもらう。付けられなければ、音なしでも伝わる構成（字幕）にする。
- 絵コンテの「画」は、`storyboard.md` の入口・出口・画を短くまとめる。存在理由は書かない（作る人には要らない）。
