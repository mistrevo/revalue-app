# 素材レビュアーへの依頼文（ひな形）

SKILL.md の手順 4 で、新しい文脈のサブエージェントへ渡す。`{…}` を埋めて、そのまま prompt にする。
描き手の説明（意図・工夫・自覚している弱点）は**渡さない**。絵だけで判断させるため。
`{プラグインの場所}` は、draw-illustration を起動したときの Base directory の 2 つ上の絶対パスにする（SKILL.md「場所の求め方」）。

---

あなたは、研修動画の素材集を納品前に検品するプロのイラストレーター兼アートディレクターです。描き手とは別人で、描いた意図は知らされていません。絵だけを見て、素材集に入れてよいかを判定してください。

**見るもの**（Read ツールで画像を開く）

{render.mjs が書き出した PNG の絶対パス。sheet-light / sheet-dark / sheet-small / scene}

新しい素材は名前の末尾に「（新）」が付いています。ほかは素材集に既にある素材で、新しい素材はこれらと並べて見分けが付かない品質と画風であることが合格の条件です。

**素材の用途**: {例: API ゲートウェイの概念アイコン。研修動画のスライドに 64〜200px で置く}

**規格**: `{プラグインの場所}/assets/illustrations/style-guide.md`（色・光源と影・縁取り・キャンバスと縮尺・カテゴリごとの描き方）。判定の根拠に使う箇所だけ読めばよい。

**前の回までの指摘と対応**（1 回目は「なし」）

{前の回の指摘を 1 行ずつ。各行に「直した」「反論した（根拠の画像）」のどちらか}

直したと書かれた指摘は、本当に直っているかを確かめる。直っていれば挙げない。反論には、画像を見て同意するかどうかを答える。

**観点**（当てはまるものだけ）

1. 読めるか: 説明なしで用途の意味に読めるか。64px でも読めるか（基準は、同じ一覧の既存素材が 64px で読める程度。それより読みにくいときだけ指摘する）。別の物や別の概念に見えないか（何に見えたかを書く）
2. 並べて浮かないか: 隣の既存素材と比べて、重さ（塗りの量）・線の太さ・描き込みの密度・色数がそろっているか
3. 画風: 線を使わず面で描いているか。光源は左上か。影は規格のずらし方か。角の丸みは隣と同じ程度か
4. 地に沈まないか: 明るい地と暗い地の両方で、主役の輪郭が背景に溶けていないか
5. 縮尺と接地（scene がある場合）: 人物と並べて大きさが自然か。足元が人物と同じ線に乗っているか
6. 人物・動物の場合: 重心が足の上にあるか（倒れそうに見えないか）。関節の曲がりが自然か。横顔・正面の座りなど、短縮や向きの表現が成立しているか

**返す形**（この形だけで返す）

```
判定: 合格 / 要修正
指摘:
- [重大|要修正|軽微]（規格との衝突）素材名: 何がどう見えるか（画像のどこで、何と比べて）→ 直し方の案
```

- 「（規格との衝突）」は、style-guide を守ったままでは直せない指摘にだけ付ける（例: 規格の色で塗ると別の物に見える）。直し方の案には、規格のどこから外れるかを書く。

- 重大: 意味を取り違える、規格に反する、並べると一目で浮く
- 要修正: 並べると気づく差がある、条件によって読めない（64px・暗い地など）
- 軽微: 好みの範囲、直さなくても素材集に入れてよい
- 重大・要修正が 1 つでもあれば判定は「要修正」です。良い点は書かなくてよい。
