# 素材を使う: 探す・置く・確かめる

素材は、人物・物・資料・アイコン・画面UI・演出パーツ・背景を、丸みのあるフラットな画風でそろえた SVG。部品ごとに `data-part` で分かれている。以下の `<共有>` は `<プラグインの場所>/assets/illustrations`、`<個人>` は `~/.claude/ns-illustrations/illustrations`。

## 使うかどうかを決める

**組む前に、その絵で伝える 1 点と、それを担う主役を決める。** 主役は、主張がそのまま形になった物か、物の状態の変化（整った資料と詰め込んだ資料、点く前と後）。人物は主役の扱い手で、主張そのものにはなりにくい。

| 主役 | 作り方 |
|---|---|
| 人物・動物・乗り物・関節で動く物・家具 | **素材を使う。描き起こさない**（形が複雑で品質が揺れる） |
| 角丸の四角・カプセル・円の組み合わせで描ける物（正面か軽い俯瞰で、部品が数個まで、関節なし） | 素材に無ければ**描き起こす** |
| 細部が意味を担う物・実物の質感が要る物 | 図解か写真・画像生成にする |

- **意味の違う素材で代用しない。** 素材は、見た人がふつう連想する意味ごと絵に持ち込む。無いなら代用せず、描き起こすか素材集へ足す。
- **イラストの画風は 1 つの資料で 1 系統にそろえる。** SVG の挿絵と、別の画風のイラストを同じ資料に混ぜない。写真は別の系統なので併用してよい。

## 探す

- **`catalog.md`**（共有と個人の両方）で素材の名前を探す。人物はロールごとに、ポーズ・向き・表情の組み合わせが表になっている。ほかは 1 素材 1 行で、大きさ・動かせる部品・差し替える文字が書いてある。
- 見た目で探すとき、利用者に素材の全体を見せるときは **`gallery.html`**（共有と個人の両方）をブラウザで開く。カテゴリ別に並び、名前で絞り込め、明るい地と暗い地を切り替えられる。絵を押すと表示中のファイル名がコピーされる。
- 描き方・色・部品の作り・ロールの設定・物の向きの組み合わせは共有の **`style-guide.md`**。
- 色は素材が持つ値のまま使う。資料の配色の変数で上書きしない。
- **向きは素材の名前で選ぶ**（`-side-right`／`-side-left` など）。`scale(-1,1)` で反転して作らない。文字が裏返り、光源の向きも逆になる。欲しい向きが無ければ構図の方を変える。
- 回して置いてよいのは、影を持たない演出パーツ（`fx-` の矢印・線など）だけ。影を持つ素材を回すと光源がずれる。

## 置く

素材の中身を HTML に**そのまま書く**。`<img src="…svg">` では部品を扱えず、色の変数も効かない。中身は手で写さず、**印を書いて道具で埋める**。印は `data-illust` に素材の名前を書いた空の `<svg>` で、次のコマンドが中身・`viewBox`・大きさを書き込む。

```
node <プラグインの場所>/scripts/fill.mjs <デッキのフォルダかファイル>…
```

フォルダなら直下の `.html` だけを見る。何度実行してもよく、素材が描き直されたら実行し直せば追従する（埋めた中身は手で直さない）。同じ名前が両方にあれば個人の素材が使われ、`個人の素材集: <名前>` の行で出る。

```html
<figure style="aspect-ratio:4/3">
  <svg viewBox="0 0 1200 900" preserveAspectRatio="xMidYMid meet" role="img" aria-label="先輩が新人に画面を指して説明している">
    <rect width="1200" height="900" style="fill:#E3E8F1"/>
    <svg data-illust="char-mentor-point-smile" data-name="mentor" x="140" y="40" data-scale="1.18"></svg>
    <svg data-illust="char-newbie-stand-normal" data-name="newbie" x="560" y="40" data-scale="1.18"></svg>
  </svg>
</figure>
```

| 印の属性 | 働き |
|---|---|
| `data-illust` | 素材の名前（`.svg` を除く）。中身と `viewBox` を素材から書く |
| `data-scale` | 倍率。`width`・`height` を「viewBox の大きさ × 倍率」で書く（縦横の倍率をそろえる）。無ければ書かない（アイコンなどは CSS で大きさを決める） |
| `data-viewbox` | 素材の一部を切り出すときの `viewBox` |
| `data-drop` | 取り除く部品（`data-part`）を空白区切りで。素材を重ねるときの上の素材の `shadow` など |

`ui-*` の素材には、飾りの文字を検査から外す `data-check-ignore="small-text contrast"` を道具が付ける（`ui-*` では手で付けない）。印の他の属性（`x`・`y`・`data-name` など）はそのまま残る。

### 並べ方

- 外側の `<svg>` を 1 つ作り、素材は 1 つずつ**入れ子の `<svg>`**（印）に入れる。`viewBox` は素材の元の値になるので、素材の座標（`data-pivot` を含む）がそのまま使える。
- 入れ子の `<svg>` には `data-name` で場面の中の役の名前を付ける（`mentor`・`doc` など）。`data-part` は素材の中の部品の名前なので、素材どうしの区別には使わない。
- 枠の地は外側の `<svg>` の最初に `<rect>` で塗る。素材は背景が透けている。
- 外側の `<svg>` の大きさは、置き先（枠・段落・ページ）の側で決める。

### 縮尺をそろえる

- 同じ場面に並べる人物と物は、素材ごとの接地線（人物と並ぶ物は y=730、動物・乗り物はキャンバスの下から 30）を外側の座標で 1 本にそろえ、倍率もそろえる。外側での接地線の位置は `入れ子の y ＋ 素材の接地線 × 倍率`。背景（`bg-*`）を敷くなら、背景の床の高さ（`style-guide.md`「背景」）もその 1 本に合わせる。
- デフォルメした絵なので、現実の物理に合わせなくてよい。伝える 1 点のために、主役を大きくして宙に浮かせるなど崩してよい。
- 縦横比が置き先と違う素材（16:9 の背景を 4:3 の枠に敷くなど）は、`data-viewbox` で素材の一部に絞って切り出す。
- **人物を大きく見せたいとき**（小さな枠・表情を見せる）は、全身を縮めずに胸から上を切り出す。人物（400×760、頭の上端 y≈114）なら `data-viewbox="0 80 400 400"` のように上半分を切り出し、下端で体が切れてよい。全身を 1:1 の枠に入れると顔が 1 割ほどになり表情が読めない。
- **小さく写る細部に意味を持たせない。** 素材は置き先によって元の半分ほどに縮む。表情の眉や口、資料の中の行は補助で、意味はポーズ・主役の物・記号（吹き出し・矢印・○×）で運ぶ。
- 主役は枠の 6 割ほどを占める大きさにする。主役以外の土台（机・椅子）は枠の端で切れてよい。

### 文字

- **読ませる文字は SVG の中に書かない。** 枠と一緒に縮んで読める大きさにならない。読ませたい文は、吹き出し（HTML の要素を絵に重ねる）か本文に書く。吹き出しは素材ではない。
- 画面UIの素材の文字（`<text data-part="title">` など）は、画面らしさを出す飾りとして書き換えてよい（`ipconfig` の結果など、場面に合う文にする）。意味は担わせない。`ui-*` ならこの除外は道具が付ける。`ui-*` 以外の素材の飾りの文字だけ、小さい字・コントラストの検査を使う環境で、入れ子の `<svg>` に手で `data-check-ignore="small-text contrast"` を付ける。**検査から外してよいのは、この飾りの文字だけ**。

### 組み合わせ

- 同じ素材を同じ絵に 2 回置いてよい（clipPath の `id` は重なるが、中身が同じなので見た目は変わらない）。
- **装着小物**（`wear-*`）は、人物の向きに合わせて選ぶ。正面は `wear-vr`／`wear-ar`、横向きは人物と同じ向きの `wear-vr-side-right`／`wear-vr-side-left`／`wear-ar-side-right`／`wear-ar-side-left`（右向きの人物に left を入れると逆を向く）。
  - 素材の `data-part="wear-vr"`（または `wear-ar`）の `<g>` を丸ごと取り出し、人物の `data-part="head"` のグループの中で `data-part="hair-front"` の直前に差し込む。`<defs>` の clipPath も人物の `<defs>` へ移す。
  - `</defs>` の後ろをまとめて写さない。left 版の外側にある反転の `<g>` まで入ると、人物側の反転と重なって逆を向く。
  - mentor に `wear-ar` を付けるときは、先に人物の `<g data-part="glasses">` へ `display="none"` を足す（メガネが二重になるため。部品は消さない）。hacker には使わない。
- 画面を持つ物（PC・モニター・スマホ）の `data-part="screen"` には、画面UIの素材（`ui-*`）を入れ子の `<svg>` で重ねられる。

### 描き起こす

素材に無い単純な物は、`style-guide.md` に沿ってその場で描く。素材と並べて見分けが付かないことを目標にする。

- 色は `style-guide.md` のトークン（機器なら `device`、画面なら `screen`）を `style="fill:var(--device-base, #3D4466)"` の形で書く。資料の配色の変数は使わない。
- 線（stroke）を使わず、塗りの面だけで作る。角は丸める。
- 影は素材と同じ作り（形を影色で塗り、同じ形の clipPath の中でベース色を左上へずらして重ねる。ずらし量は `style-guide.md`「光源と陰影」）。大きな面には左上から白 16%→0% のグラデーションを重ね、接地する物には落ち影の楕円を付ける。
- 物は正面か軽い俯瞰（天面を 1 段明るい色で見せる）。アクセント色はランプなど 1 か所・1 色。
- 動かす可能性のある部分は `<g data-part>` に分け、回すなら `data-pivot` を付ける。素材と同じく入れ子の `<svg data-name>` に入れて置く。
- 同じ絵に素材があれば、並べて描画し、色・影・角の丸みがそろっているかを目で見る。
- 他の資料でも使えそうな物は、素材集へ足す候補として報告し、`draw-illustration` で登録する。

## 確かめる

書いたら必ず描画して目で見る。部品の重なり・はみ出し・関節の外れは機械の検査では見つからない。

1. 説明を聞かずに、絵だけで「伝える 1 点」が分かるか。
2. 意味を担っているものが、置いた大きさで見えるか。
3. 足元が 1 本の接地線にそろっているか。
4. 素材どうしの重なりや、枠からのはみ出しが無いか。
5. 回した部品が関節から外れていないか（部品を回す場合）。
6. 状態を切り替える場合、途中で二重に見える所が無いか（重ねてよいのは輪郭が同じで中の部品だけ違う組み合わせ。重ねる上の素材は `data-drop="shadow"` で足元の影を除く）。

素材が足りなければ `draw-illustration` で素材集に足す。
