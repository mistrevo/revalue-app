# 挿絵素材を探して置く

素材集の SVG を、スライド・資料・HTML ページの挿絵として使う。素材は丸みのあるフラットな画風にそろえてある。

## 場所の求め方

起動した時点で表示される Base directory（`…/skills/use-illustration`）の **2 つ上がプラグインの場所**。この場所から次を組む。

- 共有の素材集: `<プラグインの場所>/assets/illustrations`
- 個人の素材集: `<ホームの絶対パス>/.claude/ns-illustrations/illustrations`（まだ無いことがある。無ければ共有だけを使う）
- 埋める道具: `<プラグインの場所>/scripts/fill.mjs`

プラグインの場所を `find` や `installed_plugins.json` で探さない。プラグインのインストール先へ書き込まない。

## 始める前に

**Node を確かめる。** 埋める道具は Node.js 20 以上で動く。`node --version` を実行し、`node` が無いか 20 未満なら、入れ方（https://nodejs.org/ の LTS 版。Windows なら `winget install OpenJS.NodeJS.LTS` でもよい）を利用者に伝えて、ここで止まる。npm やネットワークは要らない。

## 呼び出し元へ返す文言

ほかのスキルや作業から素材集の場所を尋ねられたときは、次の形で返す。`<…>` はすべて展開した絶対パスにする（`~` を残さない。呼び出し元のシェルや引数の書き方によっては展開されないため）。

```
素材集の場所: <プラグインの場所>
共有: <プラグインの場所>/assets/illustrations
個人: <ホームの絶対パス>/.claude/ns-illustrations/illustrations
埋める: node <プラグインの場所>/scripts/fill.mjs <デッキのフォルダかファイル>
```

`素材集の場所` は**プラグインの場所**（`skills/` の親）の絶対パスで、共有の素材集のフォルダではない。呼び出し元はここから `node <素材集の場所>/scripts/fill.mjs` を組む。

## 手順

1. **探す。** 共有と個人の**両方の** `catalog.md` を読んで素材の名前を決める。見た目で探すときや利用者に全体を見せるときは、両方の `gallery.html` をブラウザで開く。個人の素材集が無ければ共有だけ。同じ名前が両方にあれば個人が使われる。
2. **置く。** HTML に、`data-illust` に素材の名前を書いた空の `<svg>` を置く。
3. **埋める。** `node <プラグインの場所>/scripts/fill.mjs <デッキのフォルダかファイル>` を実行する。中身・`viewBox`・大きさが書き込まれる。何度実行してもよい。個人の素材集から取った素材は `個人の素材集: <名前>` の行で出る。
4. **見る。** 描画して、重なり・はみ出し・接地線を目で確かめる。

探し方・印の属性・縮尺のそろえ方・文字の扱い・描き起こしの条件は [references/placing.md](references/placing.md)。描き方・色・部品の決まりは共有の素材集の `style-guide.md`。

## 素材が足りないとき

主役になる素材が無ければ、`draw-illustration` を案内する（素材集へ描き足す）。その場で一度だけ使う単純な物は、placing.md の「描き起こす」に従って描いてよい。
