# SE研修動画 SVG素材スタイルガイド

Oct 16, 2026 · @照山 聖岳

## 目的と適用範囲

SE向け研修動画で使い回すSVG素材を、誰が作っても同じトーンになるようにそろえるためのルールです。対象テーマは開発プロセス、インフラ・クラウド、セキュリティ、AI活用の4つで、第1弾は共通コアを含む約40点です。

素材はHTML上で動かす前提で作ります。HyperFramesなどのHTML動画化ツールや、Webページ、スライドでそのまま使える形式にします。

- 対象：人物、物、概念アイコン、画面UI、演出パーツ、背景
- 形式：1素材1ファイルのSVG、背景は透過
- 作り手：人とAIコーディングエージェントの両方。このガイドはエージェントへの指示書としても使います

## 画風の原則

輪郭線を使わない、丸みのあるフラットベクターで統一します。科学解説アニメーションに見られる「面と影だけで立体感を出す」画風を参考にしますが、既存作品のキャラクターや構図は写しません。

- **線なし**：形は塗りの面だけで作り、輪郭線は使わない。線（stroke）は髪の流れ、口、眉、メガネなど小さな記号にだけ使う。例外として、紐・帯・ケーブル・リボンのように形そのものが一定幅の線である部品（icon-cicd の∞の帯、fx-confetti のリボンなど）は、端を丸めた線で描いてよい（帯に沿って光を流すなどの動きも付けやすい）。背景に沈まないための縁取り（「光源と陰影」の節）も線で描く
- **角は丸める**：鋭い角は避け、角丸の半径は素材の短辺の5〜15%を目安にする
- **記号的な形**：頭は楕円、手足はカプセル、手は楕円の手袋型。指や関節の描き込みはしない
- **情報量**：1素材の色数はトークン3段階×4系統まで。細部は袖口、襟、ポケット、ボタン程度にとどめる
- **文字を入れない**：素材内に文字を焼き込まない。UI素材のテキストは差し替え可能な`<text>`要素にする

## カラートークン

すべての色はベース・影・ハイライトの3段階をセットで定義し、CSS変数で参照します。SVG内では `style="fill:var(--cloth-teal-base, #2BB3AA)"` のようにフォールバック値を必ず併記し、単体で開いても色が出るようにします。fill属性などのプレゼンテーション属性ではvar()が効かない環境があるため、色は必ずstyle属性に書きます。

変数名は `--{系統}-{名前}-{base|shade|light}` です。

shade（影）は base を暗くしただけの色にせず、色相をずらします。同じ色相のまま暗くすると濁って見え（からし色の影が茶色になる）、絵が安っぽくなるためです。新しいトークンを足すときも、shade を次の規則で決めます。

- 明るさ：base より一段暗く（OKLCH の明度で、明るい色は base から 0.08〜0.14、暗色や背景色は 0.04〜0.07 下げる。今ある shade はこの範囲に入っている）
- 色相：暖色（黄・橙・赤・ピンク・茶）は赤〜赤紫の側（OKLCH の色相 355°付近）へ最大 30°、肌は赤の側へ 15°前後と控えめに回す。寒色・灰・白・暗色（青・緑・navy・device・charcoal・screen）は青紫の側（285°付近）へ最大 35°（緑と空・海の青は 22°まで）回す。無彩に近い色（灰・白・charcoal）は、影に青紫を帯びさせる
- 彩度：base を暗くしただけの色より少し上げる。背景用トークンは、前景より彩度を一段下げる既存の決まりを保ち、回す量も 20°までに抑える

## 光源と陰影

光源は全素材で左上に固定します。影は「パーツ自身の形でクリップし、その中でベース色の形を左上にずらして重ねる」方法で作り、ぼかしやドロップシャドウのフィルターは使いません。例外は icon-heatmap の熱の表現だけで、比喩そのものがぼかしなので放射状グラデーションで描きます。ほかの素材には広げません。

1. パーツの形を影色（shade）で塗る
2. 同じ形を`clipPath`にし、その中にベース色の同じ形を左上へずらして重ねる。右下に影が残る
3. 必要なパーツだけ、さらに大きくずらした形の縁にハイライト色（light）の細い線を入れる
4. 大きな面（胴体、頭など）には、左上から白の不透明度16%→0%の線形グラデーションを重ねる

影は細い三日月ではなく、下側に面として見える幅を取ります（参考の画風に近づけるため。2026-10-18 に全素材を下の値へ広げた）。x より y を大きくずらし、光が上から当たって見えるようにします。

| パーツの大きさ | ずらし量 (x, y) |
| --- | --- |
| 大（胴体、頭、コート） | (-15, -11) |
| 中（腕、脚、機器本体） | (-9, -6) |
| 小（手、耳、靴、アイコン部品） | (-5, -4) |

細い部品（指差しの指、ケーブル、毛束など）で影がベース色をほとんど覆ってしまう場合だけ、一段小さい値を使います。

接地する素材には、足元に楕円の落ち影（ink色、不透明度18〜20%）を別グループ`shadow`で付けます。落ち影は足元（接地している部分）の下に置き、お辞儀のように体を前へずらしたポーズでは、ずらした足に合わせて動かします。

全体を反転して作る左向きの素材（外側に `translate(400,0) scale(-1,1)` のような反転のグループを持つもの）は、反転すると光が右上から当たってしまいます。反転後も左上から当たるよう、次の3つを逆向きに描きます。

- 影のずらし量の x の符号
- 白のグラデーションの向き（`x1="1" x2="0"`）
- ハイライトの線（髪の流れに沿った筋など）。反転を打ち消す `transform="translate(400,0) scale(-1,1)"` を付け、左上に来るようにする

**背景に沈まないための縁取り**：明るい背景（#EEF2F6）と暗い背景（#1B1F4A）のどちらかに溶ける色が主役の部分は、外周を縁取ります。

| 主役の色 | 縁の色 | 対象と描き方 |
| --- | --- | --- |
| cloth-white | cloth-white の shade | 人物の白い服は、同じ形を線幅6で下に敷く（外へ3px出る）。上着やカーディガンの下に着た白は、外に縁を出すと上着の周りに光の輪ができるので、白い面自身のクリップの内側に3pxの線を引く。白い外装のロボット（char-ai、char-humanoid）は線幅7。白が主役のアイコン・物（雲、資料、パレット）も同じ色で縁取る |
| device・screen・navy などの暗い色 | device の light（navy は cloth-navy の light） | 家具・機器・暗い色の動物（ペンギン）・アイコンの外周に3〜4px（薄い部品は2px）。家具・機器は縁を形の内側へ回し（本体を縮めて縁に充てる）、外形の位置と大きさを変えない。外へ足すと人物や机との組み合わせで大きさがずれる |
| hair-dark の髪 | hair-dark の light | 左上側だけに2〜2.5pxのリム。前髪の毛先（顔との境）には入れない。左右対称のくさびでクリップして長い 2 本に分ける（点線に見せない）。後ろ髪は前髪と同じ外形を 3px 内側に縮め、前髪の縁にリムが残るようにする |

## キャンバスと縮尺

人物と並ぶ物（家具、機器）は、実寸ではなく3頭身の人物に合わせた縮尺で描きます。基準は接地線 y=730、椅子の座面 y≈616、デスクの天板 y=522 で、人物と同じ座標系に重ねるだけで高さがそろいます。概念アイコン・UI・演出・背景は縮尺を持たず、カテゴリごとの固定キャンバスで作ります。

| カテゴリ | viewBox | 基準 |
| --- | --- | --- |
| 人物（立ち） | 0 0 400 760 | 接地線 y=730、約3頭身で全高約615px |
| 人物（座り） | 0 0 400 760 | 座面の高さ y=600 を基準に椅子と合わせる |
| 物（家具・機器） | 家具は高さ760 | 家具は接地線 y=730。机上の物（ノートPC 0 0 200 160、モニター 0 0 260 240）は下端から20px上を天板 y=522 に合わせる |
| 概念アイコン | 0 0 200 200 | 中央に配置、外周20pxは空ける |
| 画面UI | 0 0 640 400 | 16:10、角丸半径16px |
| 演出パーツ | 素材ごと | 素材ごとに決める |
| 背景 | 0 0 1920 1080 | 16:9、人物を置く床は y=900前後 |

素材の外周には最低20pxの余白を空け、影やハイライトがviewBoxの外にはみ出さないようにします。余白に収めるために形の一部（台座、腕、ローターなど）だけを縮めたり寄せたりはしません。比率が崩れるためです。縮めるなら全体を一様に縮めます。ただし人物・机・横向きの版と座標や大きさを合わせる物（机上のノートPC、ドローンなど）は、縮めると組み合わせがずれるので、形を保ったまま余白を20px未満にしてよい例外とします（viewBoxからははみ出さない）。

## パーツ構造と支点

動かす可能性がある単位ごとに`<g>`を入れ子にし、子のグループは親の回転や移動に自動でついていくようにします。たとえば肩を回せば、ひじから先と手も一緒に動きます。

&#91;embedded content: 人物素材のグループ階層 · 4階層\]

同じ階層の中では、図の上にある部位ほど奥（SVGの前の方）に書きます。

- **支点**：各グループに `data-pivot="x y"`（viewBox座標）で回転の中心を記録する。GSAPなどでは `svgOrigin` にそのまま渡せる
- **左右**：左右があるパーツは `-L`／`-R` で対になるよう作り、片方を反転コピーして済ませない（光源の向きが逆になるため）
- **影の範囲**：clipPathはパーツごとに1つ作り、そのパーツのグループの中に閉じ込める
- **物の場合**：開閉するフタ、回る歯車、点滅するランプなど、動く部分だけを同じ考え方で分ける

## 命名規則

ファイル名は `{接頭辞}-{名前}[-{バリエーション}].svg` で、すべて小文字の英数字とハイフンにします。例：`char-newbie-pc-smile.svg`、`icon-git-branch.svg`、`obj-server-rack.svg`。

| 接頭辞 | カテゴリ | 例 |
| --- | --- | --- |
| char- | 人物 | char-mentor-point |
| obj- | 物（家具・機器） | obj-laptop、obj-desk |
| icon- | 概念アイコン | icon-bug、icon-lock |
| ui- | 画面UI | ui-terminal、ui-chat |
| fx- | 演出パーツ | fx-arrow-curve、fx-maru |
| bg- | 背景 | bg-office、bg-datacenter |
| wear- | 人物に差し込む装着小物 | wear-vr、wear-ar |

人物のバリエーションは `{ロール}-{ポーズ}-{表情}` の順に並べます。ポーズは stand、sit、point、think、trouble、表情は normal、smile、confused、surprised を使います。

部品の名前（`head`、`arm-L`、`hair-front` など）は `id` ではなく `data-part` 属性に書きます（例：`<g data-part="arm-L" data-pivot="152 382">`）。1つのHTMLに同じ人物を2人並べても名前が衝突せず、動かすときは素材の `<svg>` の中から `querySelector('[data-part="arm-L"]')` で選べます。名前は英小文字とハイフンで、左右は `-L`／`-R`（キャラクター自身から見た左右ではなく、画面上の左右）で区別します。ただし横向きの人物は `-L` が手前、`-R` が奥です（右向きで描いたときの画面上の左右。左向きは全体を反転して作るので、画面上では逆になる。「左向きと表情違い（自動で書き出す）」）。

`id` を使うのは、`url(#…)` で参照する clipPath と gradient だけです。衝突しないよう、ファイル名を接頭辞として付けます（例：`char-newbie-clip3`）。

## 左向きと表情違い（自動で書き出す）

左向きと、人物の表情違いは、元の絵から `node plugins/ns-illustrations/scripts/register.mjs --shared` が書き出す生成物です。**手で直しません**（直してもテストが落ち、次の書き出しで消えます）。直す先は次のとおりです。

| 直したいもの | 直すファイル |
| --- | --- |
| 左向き（`-side-left`） | 同じ名前の右向き（`-side-right`） |
| 表情違いの体 | 同じポーズ・同じ向きの `-normal` |
| 表情違いの顔（`data-part="face"`） | 同じロール・同じ向き・同じ表情の立ちポーズ（`-stand-{表情}`、`-stand-side-right-{表情}`） |

普通の顔の版が無いポーズ（`point-smile`、`trouble-confused` など）は、そのファイル自体が元の絵です。

**足し方**

- 新しい横向きの素材：右向きだけを描いてスクリプトを実行する。左向きはスクリプトが作る。
- 立ちポーズに新しい表情を足す：`-normal` を新しい表情の名前で複製し、顔の部品だけを描き換えてからスクリプトを実行する。
- ほかのポーズに表情を足す：`-normal` を新しい表情の名前で複製し、そのままスクリプトを実行する。顔は立ちポーズから入る。立ちポーズにその表情が無ければスクリプトが止まるので、先に立ちポーズの表情を作る。

**反転の決まり**：全体を左右反転し、光を左上のままにするため、影のずらし（`<path>` の `translate` の x）と白のグラデーションの向きを反対にします。髪のハイライトのように、反転させずに光の側（左上）へ残したい要素には、右向きの元の絵で `data-mirror="keep"` を付けます。印の付いた要素は、自分の座標系で x＝幅の半分を軸に反転し直されます。親の `<g>` が移動や回転を持つと、画面上の元の位置そのものには戻らないので、書き出した左向きを目で確かめます。印の付いた要素は、すでに `transform` を持てません。

## 人物の描き方

人物は約3頭身・点目の正面向きを基本にし、ポーズと表情はパーツの回転と差し替えだけで作れるようにします。新しいポーズのたびに全身を描き直さないことが、量産の前提です。

**プロポーション**

- 頭身：約3頭身。髪を含む頭の高さ約215px（y=114〜332）、全高約615px
- 頭：横幅164px、縦176pxの丸顔。頬がふっくらし、あごは小さくする。中心は y=240前後
- 手足：先細りのカプセル。上腕 半径20px→ひじ18px→手首16px、脚 半径22px→足首19px。腕の長さは上腕約70px（肩→ひじ）、前腕約60px（ひじ→手首）をどのポーズでも超えない。手前や奥に向く腕だけ短くしてよい
- 手：半径14×15pxの楕円。指は描かない
- 体型の違いは胴体の形（直線的、お腹が丸い、肩幅が広いなど）で出し、頭と手足の規格は変えない

**顔パーツ**

- 目：ink色のやや縦長の楕円（9×10.5px）の点目。ハイライトは入れない。目の中心間隔は64px（顔の横幅の約40%）、高さは顔の縦の約60%（y=262）
- 鼻：描かない
- 眉：長さ18pxの細い弧（線幅4px）を目の約20px上、前髪の毛先のすぐ下に。口：幅14px前後の小さな弧（線幅3.6px）を目の約27px下に置く
- 頬：目の外側斜め下に横長の楕円（15×8px）のチーク、不透明度40%
- 髪：頭にかぶった殻（ヘルメット）に見せない。2026-10-19 に newbie で試作して決めた次の決まりで描く（手本は char-newbie-stand-normal と char-newbie-stand-side-right-normal）
  - 外形：頭頂と後頭部は、頭より少し膨らむ滑らかな丸に保つ。毛先の出っ張りやギザギザで輪郭全体を崩さない（寝ぐせ頭に見える）。ヘルメットらしさは「耳を覆う側面」「一直線に切りそろえた下端」「頭の殻に沿った丸い縁」から生まれるので、そこを変える
  - 側面と後ろ：短髪は耳を見せ、もみあげは耳の付け根の上で止まる先の丸い短い形にする（前髪の束とつなげない）。横向きの後頭部は丸く張り出させ（削って垂直な壁にすると頭が縦長に見える）、下端は一直線に切りそろえず、耳たぶの高さの小さな束で首へすぼめる。耳を覆う髪型（ボブなど）は、下端を束に分けて毛先に動きを付け、切りそろえた縁にしない
  - 流れ：つむじ（頭頂のやや後ろ）を起点に、上の髪は前へ流して前髪につなぎ、後ろの髪は下へ流す。先細りの shade の帯を 3〜4 本、1 点から放射させず、起点と長さを不ぞろいにして入れる。額から後ろへ流すとオールバックに見え、正面と別の髪型になる
  - 前髪：長さの違う 3〜5 束の尖った毛先にし、束の間からおでこを少し見せる。毛先は眉の上端から 4px 以上空け、顔の輪郭の内側に収める。横向きの生え際の前端は額より前へ出さない（帽子のつばに見える）。おでこに前髪の影（肌の shade、不透明度 40%前後）を落とす
  - ハイライト：天使の輪の弧（左右対称のつや）にせず、流れに沿った先細りの短い筋（light）を 2〜3 本、左上へ置く。右向きでは data-mirror="keep" を付け、左向きでも外形からはみ出さない位置にする
- 眉、口、頬は別グループにし、表情差分ではここだけを差し替える
- 表情4種：normal（口を閉じた弧）、smile（開いた口）、confused（眉を八の字、口を波線）、surprised（眉を上げ、口を小さな縦長の楕円）

**ポーズ差分**

- 腕と脚の関節は`data-pivot`の支点で回転させて作る
- 座り（sit）だけは脚を曲げた別パーツ（太もも＋すね shin-L/R）を用意し、上半身を upper グループごと60px下げて椅子の座面 y=600 に合わせる。膝が手前に来るよう、すねを太ももの後ろに描く
- 小物を持つときは、手グループの中に小物を入れ、手と一緒に動くようにする

例外として、指差しポーズだけは人差し指を1本のカプセルで描きます。また、頭を抱えるポーズのように手が顔より手前に来る場合は、腕グループをSVG上で`head`より後に書き、顔の手前に表示します。

- マスク：開口の下半分をネックゲイター（cloth-navy、`anonymous` の中の `mask` グループ）で覆い、暗い面は目の帯だけにする

- 手：cloth-charcoal の手袋にする

**横向き**

会話、デスク作業、移動、お辞儀の場面用に、全員の横向きを用意します。ファイル名は `char-{ロール}-{ポーズ}-side-{right|left}-{表情}` です（例：char-newbie-bow-side-right-normal）。

- 顔は片目・片眉で、口とチークを顔の前側に寄せる。耳は頭の中央やや後ろに置く（髪で隠れる人物は描かない）
- 口は顔の輪郭からはみ出さないよう、線幅を含めて右端を x≤272 に収める（右向き。y=290 での輪郭は x≈279）。中心は x≈264、y≈290。開いた口（smile）は約13×10、驚きの口は楕円（rx 3.8、ry 6）。チークは cx=238、cy=285 に置き、口と2px以上離す
- 体は奥行き方向に薄くし、奥の腕と脚（-R）を手前の腕と脚（-L）の後ろに重ねる
- 右向きを基準に描く。左向きは全体を反転し、影のずらし量・グラデーション・ハイライトの線を逆向きにして、反転後も光源が左上になるようにする（「光源と陰影」の節）
- お辞儀は腰（y=540）を支点に上半身を25度傾ける。スカートのように腰から下に着る服は、傾ける上半身のグループに入れず、脚と同じ傾かない側に置く

| ポーズ | 既定の表情 | 内容 |
| --- | --- | --- |
| stand | 4種すべて | 立ち、会話の聞き手 |
| talk | smile | 片手を前に出して話す |
| walk | normal | 歩く。手前の脚を前、手前の腕を後ろに振る |
| sit | normal | 横向きに座り、両手を前（キーボードの位置）に出す |
| bow | normal | お辞儀 |

hacker の横向きは stand、walk、sit の3種だけです。ひさしを顔より前に出し、後頭部から背中へ流れるフードと、片目・マスクの横顔で描きます。

袖口のある長袖の人物（newbie、pm）は、袖口を手首の平たい楕円（幅は前腕の太さ＋2、奥行き約11px）にし、手で下半分を隠します。手を包むカプセル形にすると、卵を握っているように見えます。

## 物・アイコン・UI・演出パーツの描き方

人物以外も同じ光源と3段階の色で描き、カテゴリごとに「どこまで描き込むか」だけを変えます。

**物（obj-）**

- 正面か、わずかに上から見た角度（俯瞰10〜15度）に統一する。透視図法の奥行きは付けない
- 機器はdeviceトークンを本体に使い、ランプや画面など1か所だけテーマのアクセント色を入れる
- 画面を持つ機器（PC、モニター、スマホ）は、画面部分を`screen`という空のグループにし、UI素材をはめ込めるようにする

横向きの物は、画面や座面の前側が向く方向でファイル名を付けます（obj-chair-side-right は座面の前が右、obj-laptop-side-left は画面が左向き）。右向きの人物には chair-side-right と laptop-side-left を組み合わせます。置く位置は、右向きに座る人物（400×760）を x=0 に置いたとき、chair-side-right が x=0、desk-side が x=200、laptop-side-left が x=260・y=382（下端が天板 y=522 に乗る）です。左向きはこの並びを左右反転します。正面の机越しに人物を見せる場面では、人物の手前に desk-front と laptop-back を重ねます。

**概念アイコン（icon-）**

- 色はベース系統1つ＋アクセント色1つまで。影は小パーツのずらし量で付ける
- 動かす可能性がある部分（歯車、矢印、きらめき）は別グループにし、`data-pivot`を付ける

device や screen など暗い色が主役のアイコンは、暗い背景で沈まないよう、明るい台座（cloth-white）に載せるか、device の light 色で縁取ります。逆に cloth-white が主役のアイコン（雲、データベースなど）は、明るい背景で消えないよう cloth-white の shade 色で縁取ります。

先端技術（VR・XR・フィジカルAI・ロボット・ドローン、アクセントは accent-frontier #12B5D4）

**ヒューマノイド（char-humanoid）**：関節（device 色の球）が見える二足歩行ロボットです。白い外装は明るい背景で消えないよう、cloth-white の shade 色で縁取ります。表情はバイザーの光の形（normal＝横棒、smile＝下向きの弧、confused＝波線、surprised＝輪）で表します。ポーズは stand（表情4種）、point、carry（箱を運ぶ）、横向きの stand と walk（左右）です。横向きでは、耳を外装より一段暗い小さな円盤（cloth-white の shade）にし、バイザーを頭の前端まで回り込ませて、光の棒（目）を前端に寄せます。耳を暗い色にすると、正面を向いた目に見えるためです。

**装着小物**：VRヘッドセットと ARグラスは、人物と同じ 400×760 の座標で描いた部品です。人物の向きに合わせてファイルを選びます。

| 正面 | wear-vr.svg | wear-ar.svg |
| 右向き（char-*-side-right-*） | wear-vr-side-right.svg | wear-ar-side-right.svg |
| 左向き（char-*-side-left-*） | wear-vr-side-left.svg | wear-ar-side-left.svg |

横向きの頭の骨格（輪郭・目・耳）は全ロールで共通なので、どの人物・どのポーズにも同じファイルが合います。

- 差し込むのは素材の `data-part="wear-vr"`（または `wear-ar`）の `<g>` だけで、人物の `data-part="head"` のグループの中、`data-part="hair-front"` の直前に入れる。`<defs>` の clipPath も一緒に移す
- left 版は単体で開いても左を向くよう、外側に反転の `<g>` を持つ。人物の left 版も同じ反転を外側に持つので、この反転の `<g>` は差し込まない（入れると二重に反転して逆を向く）
- 頭の中に入るので、頭を動かしたりお辞儀したりすると一緒に動く
- mentor は自前の丸メガネ（`glasses`）が ARグラスと二重になる。wear-ar を使うときは `glasses` の `<g>` に `display="none"` を付けてから差し込む（部品は消さない。VR では箱に隠れるので不要）

この世界の素材の縮尺はデフォルメで、実物どうしの大きさの比は再現しません。人物と並べて違和感のない大きさにそろえることを優先するため、次のような差がそのまま残ります。

- 二輪（obj-roadbike、obj-citybike、obj-scooter、obj-motorcycle）は人物の高さの約0.3倍で、人物を乗せる大きさではない。人物が乗る絵は用意しないので、「自転車で通勤する」などは人物と乗り物を並べて表す
- 列車の高さは、obj-bullet-train が人物の約0.4倍、obj-train が約0.5倍で、バスより低い
- 動物は種によらず、ほぼ同じ大きさ（360×400 のキャンバスいっぱい）に描く。牛と兎も同じ大きさになる

大小の違いを見せたい場面では、素材を描き直さず、スライドの HTML 側で拡大縮小して並べます。

**動物の描き方**：人物と同じ点目・チーク・小さな口で、可愛さを人物にそろえます。そのうえで、次の 4 つを守ります（2026-10-18 に全 24 点をこの決まりで描き直した）。

- 形：楕円の頭・楕円の胴・同じ形の脚を貼り合わせない。胴と頭はひと続きのシルエットにし（胸を上げ、首を作る）、腰には太ももの丸みを別の部品で重ね、脚は先細りにして足先を少し広げる
- 奥の部品：画面の奥側の脚・翼・ひれは、手前から少しずらし、shade に ink を不透明度 20%前後で重ねた一段暗い平塗りにする（影の方式はかけない）
- 差し色：1 匹 1 色にしない。首輪・胸元・口元・足先・模様などで別系統の色を 1〜2 つ足す（1 素材の色数の上限は人物と同じ）。模様（しま、ぶち）は体の形でクリップし、体と同じ影を受けさせる。模様を一段濃く見せるだけなら ink を不透明度 13%前後で重ねる
- 淡い色の動物（灰の猫、白の牛・兎）は、全身の色を変えず、差し色と模様で背景から浮かせる

乗り物は車輪（wheel-\*）、自転車のクランク（crank）、ヘリコプターの回転翼（rotor）、地球の大陸（land）、ロケットの炎（flame）、太陽の光線（rays）を別グループにしてあり、回転や点滅に使えます。実在の車両・建物・ランドマークには似せません。

**画面UI（ui-）**

- 実在のアプリやOSの見た目は再現しない。ウィンドウは角丸の四角とタイトルバーの3つの丸だけで表す
- テキストやコードは`<text>`要素で入れ、`data-part`（`title`、`line1`〜）で差し替えられるようにする。フォントは等幅を `font-family="'JetBrains Mono',monospace"`、ゴシックを `font-family="'Zen Kaku Gothic New',sans-serif"` と書き、埋め込まない。使う側の HTML が Google Fonts から読む書体と総称だけを書き、システムのフォント名（Menlo・Consolas・Hiragino Sans・Yu Gothic UI など）を並べない（環境ごとに当たる書体が変わり、見た目がそろわない。video-slides で使う場合は、deck-flow の取り込みと mp4 の書き出しが HyperFrames の検査で止まる）。太さは 400・700・900 のどれかにする

**演出パーツ（fx-）**

- 矢印、ハイライト枠、番号バッジ、○×、集中線、紙吹雪を用意する
- 吹き出しは SVG の素材にしない。中身が文字で、大きさは文字で決まるため、使う側の HTML の部品で描く（video-slides で使う場合は deck.css の .balloon・.balloon--think）。画風は素材に合わせ、白の塗りと ink 色の線（線幅4px）で縁取る
- 色はCSS変数で外から変えられるようにし、影は付けない（人物や物と区別するため）

演出パーツの色は `--fx-color`（線・記号の色）のCSS変数で変えます。fx-speedlines のように既定の色が ink のものは、暗い背景ではほぼ見えないので、`--fx-color` を白などの明るい色に変えて使います。複数色の fx-confetti は、5色のうち1色を `--fx-color`（既定 #F2B33D）、残りをアクセント色トークンで塗り、奥の小片 `confetti-back` と手前の大片 `confetti-front` に分けてあります（視差を付けて動かせる）。HTML の吹き出しの塗りは `--fx-fill` で変えます。

**背景（bg-）**

- 彩度を前景より一段下げ、人物や物が埋もれないようにする
- 奥・中・手前の3レイヤーをグループに分け、視差を付けて動かせるようにする
- 暗い背景（bg-space 系）では、人物の胴の高さ（y 550〜850 前後）を bg-space の shade に近い暗さに保つ。チャコールの服は bg-space の light と明るさが近く、背後をほんのり明るくするとかえって沈む。明るさを足すのは足元の床の光にとどめる
- 床に置く物（棚・コンベアなど）は、脚や支柱を床の線まで描いて浮かせない
- 背景の光（スポットライトの光だまりなど）は、放射状グラデーションでぼかさず、glow の平塗りの楕円を重ねた濃さの段差で表す
- 人物と同じ奥行きに立つ物（街灯・街路樹・ベンチ）は人物の縮尺に合わせる。建物は通りの向こうへ下げて遠景にする（bg-city は建物の足元 y=700）
- 人物を置く床の高さ：ステージ・街並み・公園（bg-stage、bg-city、bg-park）は y=900 前後、オフィス y=860〜、データセンター y=820〜、工場 y=860〜、抽象の2種 y=900〜。bg-orbit は軌道上の展望デッキで床は y=876〜。地球の地平線は人物の肩の高さ（y≈610）に置き、人物は手前のデッキに立つ

第1弾の背景は bg-office、bg-abstract-light、bg-abstract-dark の3種です。人物を置く床は、オフィスが y=860〜、抽象の2種が y=900〜です。

## 書き出しと納品前チェックリスト

素材はSVGのまま納品し、PNGはプレビュー用にだけ書き出します。手で描いた素材もエージェントが生成した素材も、次の項目をすべて満たしてから素材フォルダに入れます。

- [ ] ファイル名とviewBoxがこのガイドの規格どおりになっている
- [ ] 背景が透過で、外周20pxの余白がある
- [ ] 色がすべてカラートークンの値で、CSS変数とフォールバック値が併記されている
- [ ] 線（stroke）が記号的な小パーツだけに使われている
- [ ] 影が左上光源の向きで、ずらし量が規格の範囲内にある
- [ ] 動かすパーツがグループに分かれ、`data-pivot`が付いている
- [ ] 部品の名前が `data-part` に書かれ、`id` は clipPath と gradient だけで、ファイル名の接頭辞が付いている
- [ ] 文字が焼き込まれておらず、UIのテキストは差し替え可能な`<text>`要素になっている
- [ ] 他の素材と並べたプレビューで、縮尺と色調が浮いていない
- [ ] 既存作品のキャラクター、ロゴ、実在人物に似ていない

プレビューは、明るい背景（#EEF2F6）と暗い背景（#1B1F4A）の両方で確認します。
